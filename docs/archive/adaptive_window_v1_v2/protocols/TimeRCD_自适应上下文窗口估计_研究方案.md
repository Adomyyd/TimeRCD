## 0. 摘要

TimeRCD 在主实验中对所有数据集使用固定窗口 5000，论文的窗口敏感性实验显示最佳窗口因数据集而异【核实】。研究目标是在不改动、不重训 TimeRCD 的前提下，估计逐序列检测窗口：估计器读取原始序列，从少量候选窗口中选出一个，TimeRCD 只在该窗口配置下运行一遍官方分块推理。下文的“单次前向”均指这一配置级推理，不表示整条长序列只调用一次底层网络。当前没有获准训练的学生或可信教师。

原设计拟用冻结 TimeRCD 的无标签自评估生成候选窗口区间 \( [W_{\mathrm{lo}},W_{\mathrm{hi}}] \)。以下两条规则现作为暂停的备选设计保留：

- 原称“下界”的 \( W_{\mathrm{lo}} \)：在疑似正常区域遮挡 patch，取重建误差接近候选最优值的最小窗口。现有证据不足以把该统计量解释为检测上下文够用，更未证明其具有下界性质。v1/v2 是自定义探针，不是原版训练任务的严格复现。
- 原称“上界”的 \( W_{\mathrm{hi}} \)：受 Lepski/ICI 启发，从 \(W_{\mathrm{lo}}\) 开始检查跨窗口异常分数一致性。该规则依赖尚未成立的重建代理，只表示尺度敏感性，不等同于检测到有害混杂，也不因下界路线暂停而自动成为替代教师。

原计划用候选集（partial-label）损失将离线区间教师摊销为学生，部署时不运行教师。本文保留相关公式及成本设想；这些内容不代表已经得到有效教师或检测收益。

需分开判断三件事：重建头能否运行、探针对重采样是否稳定、探针偏好是否对应检测窗口效用。第一项已通过实现检查；v1/v2 未通过第二项；第三项尚未验证。原三关验证框架和失败记录保留。训练调用链复核说明代理依据不足，但不构成新的实验反证，也不改变已有 Gate 判定。

## 1. 背景与动机

### 1.1 TimeRCD 的窗口机制

- **推理分块。** 公开推理代码先对整条序列做全局 z-score，再按 `min(len, win_size)` 切成互不重叠的块，末块用最后一行补齐并加掩码，各块独立推理【核实】（`time_rcd/_inference.py` 的 `_WindowDataset`；基准分支 `utils/dataset.py` 的 `TimeRCDDataset(stride=win_size, normalize=True)` 同理）。
- **默认值。** `detector.py` 中 `DEFAULT_WIN_SIZE = 5000`，需要人工设置，没有自动选择机制【核实】。
- **含义。** "窗口"在本方案中指上述 `win_size` 块长。窗口决定了 RCD 判别时每个点能参照的上下文范围。改变窗口的同时也会移动块边界，这是一个混杂因素，第 4.3 节和第 8.6 节专门处理【推断】。
- **长度范围。** 预训练序列长度为 100–10000【核实】，因此 10k 以上的窗口属于长度外推。论文 Table 11 中 15k 窗口在部分数据集上仍然最好【核实】。

### 1.2 现有证据显示的余量

论文附录 Table 11 给出 1k–15k 窗口下 11 个单变量数据集的 VUS-PR。按数据集取平均【核实，数值由我们根据该表计算】：

| 策略 | 平均 VUS-PR |
|---|---|
| 固定 5k（主实验协议） | 50.55 |
| 最优全局固定窗口（3k） | 51.34 |
| 逐数据集 oracle | 54.55 |

逐数据集最佳窗口差别很大：SED 3k、WSD 3k、Stock 1k、UCR 15k（约 6k 后基本持平）、Power 15k；NEK 与 YAHOO 对窗口不敏感。相对 5k 的 oracle 增益集中在 SED（+12.61）、Power（+11.04）、WSD（+7.54）、Stock（+3.94）、UCR（+3.87）【核实】。

需要注意两点【推断】：

1. SED 只有 3 条序列，Power 只有 1 条（Table 8），两者贡献了相对 5k 总增益 4.0 中的 2.15。按数据集平均会放大小数据集的权重，因此必须在逐序列层面重新测量余量（第 8.2 节，关卡 1）。
2. README 的 2026.04 公告说明发布了新数据和新权重、单变量 VUS-PR 绝对提升 6.7；不能据此认定当前论文使用更早权重。2026-11-02 核对已有 700 条固定 5k 单变量结果，其 11 个数据集宏平均 VUS-PR 为 50.5502%，与 [arXiv v5 Table 1](https://arxiv.org/html/2509.21190v5#S3.T1) 的 50.55% 基本一致【核实】。本地 checkpoint 哈希匹配 HF 官方文件，但论文未公布权重哈希，旧运行日志也未记录哈希，故无法证明精确二进制身份。当前权重的逐序列窗口余量仍需实验确认，不能仅由数据集汇总值推定【需核实】。

### 1.3 研究问题

> **RQ：** 冻结 TimeRCD 的窗口偏好，能否只凭序列自身结构（长度、可选周期/统计尺度、状态切换、自相似性）预测出来，并在同一候选集、同等标签权限下，稳定超过开发集选定的最优全局固定窗口？测试集后验最优窗口只作不可部署的 oracle 上界。

这是一个可证伪的问题。答案为否同样有信息量，但不能直接归因于异常内容：还需排查教师标签噪声、特征遗漏、学生容量和跨来源分布偏移；只有这些解释得到控制后，才讨论其与问题 2 的关系【推断】。

## 2. 问题定义与基本假设

### 2.1 符号

- 序列 \( x\in\mathbb{R}^{T} \) （先做单变量），长度为 \( T \) 。
- 原始候选窗口表 \(\mathcal{W}_5=\{W_1<\dots<W_5\}=\{1000,2000,4000,8000,16000\}\)。对短序列以 \(\min(W_k,T)\) 截断并合并重复项，后续用 \(\mathcal{W}(T)\) 表示该序列去重后的有效候选。
- 去重后每条序列有自己的有效候选集合 \(\mathcal{W}(T)=\{\min(W_k,T)\}_{\mathrm{unique}}\)。学生 softmax 只在有效候选上归一化，重复候选不得作为多个类别重复计权；训练、推理和评估均使用同一映射。若有效候选仅一个，该序列不参与窗口选择损失，但仍计入固定配置效用与覆盖率报告。
- 冻结的 TimeRCD 在窗口 \( W \) 、分块偏移 \( o \) 下的输出异常分数为 \( s^{(W,o)}=F(x;W,o)\in[0,1]^{T} \) 。官方推理对应 \( o=0 \) 。
- 检测效用 \( U(x,W,o) \) ：在有标签数据上用窗口 \( W \) 和分块偏移 \( o \) 计算 VUS-PR，只用于评估、基线及明确标注的有标签标定版本，不作为主学生的逐序列监督；记 \( U(x,W)=U(x,W,0) \)。全文效用按 0–100 计分，若实现返回 0–1，则先乘以 100。

主方法教师和学生均使用 \(\mathcal{W}_5\) 及其按序列长度截断后的 \(\mathcal{W}(T)\)。密集窗口网格只用于评测和诊断，不能与学生训练使用的候选集混用。

为使后文公式简洁，在讨论单条序列时将 \(\mathcal{W}(T)\) 简写为 \(\mathcal{W}=\{W_1<\dots<W_K\}\)，此时 \(K\) 是该序列有效候选数（默认上限 5），\(W_1\) 也是其实际最小候选。跨序列比较固定窗口时，\(W\) 指原始配置，并按各序列长度截断；oracle 的单条序列最值则在有效候选上计算。

评测时另定义 \(\mathcal{W}_{\mathrm{eval}}=\{1000,2000,\ldots,16000\}\)，用于近似逐序列效用上界；报告学生相对 oracle 的差距时，必须注明 oracle 是在 \(\mathcal{W}_5\) 还是 \(\mathcal{W}_{\mathrm{eval}}\) 上计算。主方法的学生只能选择 \(\mathcal{W}_5\) 中的窗口。

### 2.2 假设（弱化后的版本）

原始设想是"每条序列存在一个合适的窗口"。考虑到效用曲线常常平坦（如 YAHOO、NEK），我们改为【推断】：

> **H1（区间近似假设）：** 相对冻结的 TimeRCD，近优候选通常能用单个连续区间近似表达，且内部不夹杂显著低效用窗口。区间由三个因素约束：
> - **充分性**：窗口应包含对异常检测有用的局部或长程信息，不要求序列一定存在周期；patch 重建能否充当代理尚无验证，不作为充分性的定义或已成立的测量；
> - **同质性**：窗口不宜跨越太多状态切换，否则参照模式混杂；
> - **低污染**：窗口内异常过多或重复可能使异常被吸收进参照（论文 Limitations 已指出这一风险【核实】，对应问题 2）；本方案的一致性规则并不直接测量异常密度或污染程度。
>
> **H2（可预测性假设）：** 区间位置主要由可从原始序列结构统计估计的因素决定。由于教师区间还可能受异常污染影响，H2 额外隐含假设：该影响较弱，或能由现有无标签结构特征间接预测。这是本研究最脆弱、也最需要证伪的部分。

H1 只是待检验假设，不保证实际近优候选集合连续；第 8.3 节保留区间内部效用检查设计。关键代理假设是：patch 重建对窗口的偏好与异常检测对窗口的偏好有足够关联。若模型仅靠邻近点完成重建，该探针可能漏掉检测所需的长程信息【推断】。目前缺少支持该关联的证据，故暂停将重建误差用作教师；稳定性即使达标也不能代替效用验证。原 Gate 2/3 分别检查代理与 H2，不能混淆失败归因。

## 3. 原区间方案总览（暂停，保留设计）

以下流程描述原方案，当前不执行教师生成或学生训练。原训练中的辅助重建收益不能证明该流程的窗口监督有效。

```
训练阶段（离线，TimeRCD 冻结）
  无标签语料 x ──► 教师（多窗口 patch 重建 + 多窗口/多扰动异常评分）──► 区间 [W_lo(x), W_hi(x)]
            └───► 学生特征 φ(x), ψ(x, W_k) ──► 学生 p_θ(k | x) ◄── 候选集损失（落入区间）

推理阶段（在线）
  x ──► 特征 φ(x), ψ(x, W_k) ──► 学生 ──► k̂ = argmax p_θ(k | x) ──► TimeRCD 在 W_k̂ 下前向一次 ──► 异常分数
```

设计约束与理由：

| 约束 | 做法 | 理由 |
|---|---|---|
| 推理只选择一次 TimeRCD 窗口配置 | 学生只读原始序列；部署不运行默认窗口探测、重建探针或多窗口比较，只调用所选窗口的一遍官方分块流程 | 控制在线额外成本；长序列仍会按官方逻辑包含多个底层块级前向 |
| 不重训 TimeRCD | 冻结全部权重，只训练学生 | 在预训练中联合训练估计头需要重训基础模型，代价大一个量级【推断】 |
| 不用异常标签做主监督 | 原拟用重建头与跨窗口一致性，当前暂停 | 只有独立证据支持代理且新协议获准后，才讨论元标签；不能把合成异常标签用于探针选择或主教师监督 |
| 候选窗口离散且少 | \( K\approx5 \) ，监督表预先算好 | 训练变成普通监督学习，不需要 Gumbel-softmax 一类松弛【推断】 |

## 4. 原教师设计与训练溯源

原教师拟在离线阶段使用更多偏移和掩码，与学生共享 \(\mathcal{W}_5\) 候选集；更密窗口网格只用于 oracle 和敏感性诊断。第 4.2–4.4 节保留旧公式与边界规则，不作为当前可执行方法。

### 4.1 原版联合训练、来源纠正与适用边界

**可调用性已核实。** 本地官方 uni checkpoint 含 6 个 `reconstruction_head.*` state-dict 键，按自带配置 strict load 成功，patch size 和 embedding 输入宽度均为 16【核实】。重建头是作用于逐点嵌入的 3 层 MLP（\(d_{\mathrm{proj}}\to4d_{\mathrm{proj}}\to4d_{\mathrm{proj}}\to1\)）。官方检测使用未遮挡输入与异常头；保留重建头权重只说明能调用，不能证明其适合窗口选择。

**训练来源纠正。** 官方历史版本 [`792392d7` 的完整 `training.py`](https://github.com/thu-sail-lab/Time-RCD/blob/792392d7fe835475f08f00180cb8b5788f8b7762/training.py) 使用零填充，在 `main()` 中通过 `config = default_config` 修改共享配置，将 patch size 设为 16；上游于 2026-06-13 的 `609476ad` 提交删除该入口【核实】。因此，不能把零填充归为本地 fork 独有改动，也不能仅凭配置类默认值 4 就认定完整训练入口存在 4/16 不匹配。

当前官方版本 [`372bb980` 的 `TimeRCD_pretrain_multi.py`](https://github.com/thu-sail-lab/Time-RCD/blob/372bb980426b2f67007311c6f3165ab789c79bef/time_rcd/_core/TimeRCD_pretrain_multi.py) 中，保留的 `create_random_mask()` 辅助函数使用 `randn*0.1`【核实】。需区分这个辅助函数与历史完整训练调用链；二者都不能单独证明当前 checkpoint 实际采用的填充值。checkpoint 的 SHA256 为 `be8906c6a62f16cedd8fe0fe48ef11c4363099633ed6ba8780af819337f7ffaa`，与此前核对的 HF 官方文件一致；它记录 epoch 6 和 patch size 16，但没有训练 commit 或 mask/fill 溯源字段【核实】。

**历史完整入口的训练流程：**

```text
含注入异常的 time_series、原始异常标签
  → 全序列标准化、padding
  → 随机选择约 15% patch，在 embedding/Transformer 之前置零
  → 共享 Transformer（有效 attention mask = 非 padding 且未遮挡）
  → 同一份逐点表示
      ├─ 重建头：仅在被遮位置计算对原 time_series 的 MSE
      └─ 异常头：按原始标签计算交叉熵，不另排除被遮位置
  → recon_loss + anomaly_loss，权重均为 1，反向更新共享编码器与两个头
```

历史入口随机遮挡时不排除异常位置，重建目标使用 `time_series` 而非 `normal_time_series`【核实】。所以该任务包含恢复被遮异常原值，不是仅在正常位置重建或恢复正常底稿的去噪任务。被遮 patch 保留 Query 和残差表示，attention mask 阻止其作为 Key/Value 被关注；占位值仍可能影响重建【核实】。当遮挡消除了异常数值或类别的关键信息时，剩余输入可能不足以确定目标【推断】；尚无本项目实验量化这一风险或证明有害梯度冲突，不能用它解释 v1/v2 的失败。

**论文交代的范围。** 对 [arXiv v5（2026-05-29）](https://arxiv.org/html/2509.21190v5) 正文 2.2、附录 C.4、D.5、E.5 的核对中，未找到专门讨论“异常位置被遮后仍以异常原值重建”的说明，也未找到“排除异常重建目标”与“不排除”的针对性消融。该结论只限于已核对章节。论文 Table 3 在 UCR 上报告联合训练后异常头 VUS-PR 为 33.57、仅异常目标训练为 5.90、联合训练后用重建误差打分为 4.08【核实】。这些结果支持该设置下辅助重建的整体训练收益，但不隔离异常位置参与重建的影响，更不是窗口选择检验。

**与本研究的差别。** 原版训练随机遮挡多 patch 并更新模型；v1 固定跨窗口目标、筛疑似正常位置并冻结模型；v2 又改为目标居中片段、单 patch 遮挡、局部插值和成对噪声。官方检测则不遮挡，以 `offset=0` 非重叠块输出异常头分数。低异常分数筛选不能保证目标正常，也不能把混合数据联合训练的重建头变成正常条件分布模型。原训练支持辅助表征学习，尚不支持“重建误差偏好的窗口能指导检测”这一额外假设。因此暂停教师路线；这项方法判断不新增实验失败原因，也不否定整个自适应窗口方向。

### 4.2 原称“下界”的 \( W_{\mathrm{lo}} \)：暂停的掩码重建假设

**原设想。** 在疑似正常区域遮盖一组 patch，比较不同窗口的恢复能力，选择重建误差接近候选最优值的最小窗口。误差不保证随窗口增大而单调下降，该统计量也没有检测窗口下界保证【推断】。离线使用不消除代理失配；下列公式仅保留为历史操作定义，不能作为可信教师。

**疑似正常 patch。** 先用默认窗口 \(\min(5000,T)\) 运行一次官方推理，得到 \(s_0\)。按预训练掩码单位 \(p_{\mathrm{pre}}\) 对齐划分完整 patch，计算各 patch 内 \(s_0\) 的均值；均值不超过所有完整 patch 均值的 \(q_{\mathrm{norm}}\) 分位数者，记为合格 patch（默认 \(q_{\mathrm{norm}}=0.5\)）。这是模型自筛选的“疑似正常”，不保证真实正常，可能继承默认窗口的漏检偏差【推断】。这里的 \(q_{\mathrm{norm}}\) 与第 4.3 节高分点比例 \(q_{\mathrm{top}}\) 分开定义。

**原设计的掩码形式。** 原计划每条序列采样 \(M=4\) 个随机 patch 掩码样本，每个样本使用独立输入副本，不叠加到已经遮挡的序列上；诊断实际锚点数以第 8.3 节及产物为准。已执行 v1 采用 patch size 16、\(\rho=0.15\)、标准化坐标下 `randn*0.1` 填充，零填充作对照。不再以当前辅助函数宣称复现 checkpoint 训练；历史完整入口使用零填充，且启动时已将共享 patch size 改为 16（第 4.1 节）。本次不据此重跑或更改 v1/v2 协议。

**锚点及位置多样性。** 锚点在整条序列上采样，而不是限制在序列开头的最小窗口内。将时间轴划为 \(M\) 个区间，优先在不同区间内随机选择有效锚点；有效意味着以该点为中心的最小候选窗口包含足够的合格 patch。初始最小锚点间距取 \(d_{\min}=W_1/2\)，属于预设的去冗余约束，不是已验证的最优值。若正常位置分布无法满足，不采入高分区域或强行填满，而是减少有效样本数 \(M_{\mathrm{valid}}\) 并记录覆盖范围。

**固定遮挡目标。** 对第 \(m\) 个锚点，先截取最小候选窗口，记其中完整 patch 数为 \(N_{p,m}\)，从合格 patch 中无放回抽取 \(\max(1,\lfloor\rho N_{p,m}\rfloor)\) 个作为遮挡目标。分母是该窗口的完整 patch 总数，不是合格 patch 数；若合格数不足或没有完整 patch 则该锚点无效。所有候选窗口复用相同目标位置、原始目标值及填充噪声。仅保留对所有候选窗口都完整有效的掩码样本，避免不同窗口在不同位置上计算误差。

固定目标意味着大窗口的整体遮挡比例低于 \(\rho\)，且目标集中于共同锚定区域；疑似正常区筛选也改变了原训练的均匀采样分布。patch size 与历史入口/权重一致不表示填充值、采样分布或任务已对齐。每窗固定比例但允许新增遮挡仅是旧版敏感性对照设想，不在当前暂停状态下执行。

连续段掩码不参与原主教师标签、流程或成本估算，也不依赖周期估计生成掩码。探索其他掩码须另行注册；不能用更长遮挡默认迫使冻结模型有效利用长程信息，或据此绕过代理依据与 Gate 2 失败。

**取窗和前向控制。** 对每个锚点取长度为 \(W\) 的片段，贴边时向内平移并保证窗口嵌套、目标完整；切片起点、TimeRCD patch embedding 的网格原点、末端 padding 与 mask 位置必须按预训练代码一致处理。若候选边界不能同时对齐预训练 patch 网格，则要明确实际有效窗口长度并把它纳入候选定义，不能只在文档中假定对齐。以整条原序列的均值和标准差标准化一次，然后取片段、施加掩码；不对不同窗口各自重算均值/方差。模型处于 `eval` 模式，冻结全部权重，固定每条序列的采样种子和填充噪声。这样减小边界、归一化和随机性混杂，但不能完全消除它们【推断】。误差公式中的 \(x^{(W)}_m\) 和 \(m^{(W)}\) 分别表示该窗口内标准化后的未遮挡目标片段和对应掩码，\(\mathcal{M}_{\mathrm{patch}}\) 只包含共同有效样本。

**历史重建误差与窗口选择规则（保留符号，不主张下界性质）：**

$$
R_{\mathrm{patch}}(W)
=\frac{1}{|\mathcal{M}_{\mathrm{patch}}|}
\sum_{m\in\mathcal{M}_{\mathrm{patch}}}
\frac{\big\|m^{(W)}\odot(\hat{x}^{(W)}_{m}-x^{(W)}_{m})\big\|_2^2}{\|m^{(W)}\|_1}
$$

$$
W_{\mathrm{lo}}
=\min\Big\{
W_k\in\mathcal{W}:
R_{\mathrm{patch}}(W_k)
\leq
(1+\varepsilon)\min_{j}R_{\mathrm{patch}}(W_j)
\Big\}
$$

该式只给出重建近优的最小候选，不证明检测所需上下文的充分性。原设计未加入连续段掩码；当前也不追加消融或生成 \(W_{\mathrm{lo}}\) 教师标签。

**独立备选路线（仅保留设想，未授权执行）**：异常头的“注入—恢复”代理曾列为备选，接近 Goswami 等（ICLR 2023）的注入代理思路【原方案引用，具体方法需核实】，其结果依赖注入类型分布【推断】。当前不将其替换为教师，不用合成异常标签选择探针或生成主监督。任何替代路线须另立协议并获得执行确认；主探针失败或弃权不自动放行替代方法。

### 4.3 原称“上界”的 \( W_{\mathrm{hi}} \)：一致性启发式（暂停）

该旧规则依赖第 4.2 节的代理起点，未获独立放行；不因重建路线暂停而继续生成区间标签。

**来源。** 非参数统计中的局部带宽选择：从小带宽开始逐步放大，只要新估计与所有更小带宽的估计在噪声范围内一致就继续，一旦出现超出噪声的偏离，就认为大带宽引入了偏差并停止。代表方法有 Lepski 方法（Goldenshluger & Lepski, 2011）和 ICI 规则（Katkovnik, 1999）【核实】。这里把"带宽"换成上下文窗口，把"估计"换成异常分数序列【推断】。

**移植边界。** 这里没有已知的无偏估计目标、带宽偏差单调性或具有覆盖保证的置信区间，秩/Jaccard 差异也不是原统计估计误差。因此仅保留“随尺度扩大检查一致性”的关系结构，将其作为经验启发式，不继承 Lepski/ICI 的理论保证。若代理假设和校准实验不支持，该移植在本任务上即不成立。

**扰动参照尺度 \( \delta_W \) 。** 同一窗口下，改变分块偏移 \(o\in\mathcal{O}_W=\{0,\lfloor W/3\rfloor,\lfloor2W/3\rfloor\}\)，并去重。偏移 \(o>0\) 时，块边界位于 \(o+nW\)，\([0,o)\) 作为短块单独推理。偏移既改变边界，也改变各点实际看到的上下文，可能包含系统性结构差异；所以 \(\delta_W\) 只是敏感性参照，不是纯噪声方差或标准误【推断】：

$$
\delta_W=\frac{2}{|\mathcal{O}_W|(|\mathcal{O}_W|-1)}\sum_{o<o'}D\big(s^{(W,o)},\,s^{(W,o')}\big)
$$

**跨窗口差异 \( \Delta_{jk} \) 。** 先对偏移取平均 \( \bar{s}^{(W)}=\frac{1}{|\mathcal{O}_W|}\sum_{o}s^{(W,o)} \) ，再计算

$$
\Delta_{jk}=D\big(\bar{s}^{(W_j)},\,\bar{s}^{(W_k)}\big)
$$

**共同有效位置。** 先对全部候选窗口及其偏移取完整块位置的交集，记为 \(V\)。所有 \(\delta_W\) 与 \(\Delta_{jk}\) 都在同一组原始时间坐标 \(V\) 上计算，不能让噪声尺度和跨窗口差异来自不同区域。\(|V|\) 的最低要求在开发阶段预设；若交集为空或过少，则对该序列的所有候选统一切换为下述裁剪扰动，不以“差异为零”代替缺失比较。

**短序列/有效区域不足时。** 对所有候选统一使用三种输入：不裁剪、从头裁去约 \(0.1T\)、从尾裁去约 \(0.1T\)。使用原序列的同一组标准化参数，对每个版本按 \(\min(W,T_{\mathrm{version}})\) 分块，再把分数映射回原时间坐标，只在共同保留区域比较。此时上式的偏移集合替换为三个裁剪版本，\(\delta_W\)、\(\bar{s}^{(W)}\) 和 \(\Delta_{jk}\) 均由同一套裁剪输出计算。裁剪会改变可用内容，不等同于偏移噪声，需单独报告该子集并验证规则是否仍可靠【推断】。

差异函数 \(D\) 有两个候选：\(1-\rho_{\mathrm{Spearman}}\)，或者 \(1-\mathrm{Jaccard}(A,B)\)，其中 \(A,B\) 分别是两组分数在 \(V\) 内最高 \(q_{\mathrm{top}}\) 比例的位置集合（默认 \(q_{\mathrm{top}}=5\%\)，至少取 1 点）。并列分数使用固定规则处理并记录并列比例；常数分数、非有限值或 Spearman 无定义时不能判为“一致”，而应标记比较无效。不同候选整体都稳定但持续漏检的情形，两种差异也无法识别。

**上界：**

$$
W_{\mathrm{hi}}=\max\Big\{W_k\in\mathcal{W}:\ W_k\ge W_{\mathrm{lo}},\ \Delta_{ji}\le\kappa\max\big(\delta_{W_j},\delta_{W_i}\big),\ \forall\,W_{\mathrm{lo}}\le W_j<W_i\le W_k\Big\}
$$

**为什么从 \(W_{\mathrm{lo}}\) 开始检验。** 窗口增大可能带来有用信息，也可能混入异质状态或重复异常。一致性本身不能分辨好坏。我们仅假设：patch 重建已经近优后，检测分数的额外大幅变化更可能提示不适配；这不是从下界公式必然推出的结论，尤其模型可通过局部插值完成 patch 重建时会失效【推断】。第 8.3 节须同时验证下界代理和上界截断是否损伤检测效用。\(\kappa\) 是经验容忍系数，不应解释为“几倍标准差”；过大的 \(\delta_W\) 也可能掩盖真实窗口效应。

### 4.4 教师输出与边界情况

- 有效探针输出 \(S(x)=\{k:W_k\in\mathcal{W}(T),\ W_k\in[W_{\mathrm{lo}}(x),W_{\mathrm{hi}}(x)]\}\)。按构造非空；弃权样本令 \(S(x)\) 等于该序列全部有效候选，而非原始重复类别。这只是候选标签区间，不是统计置信区间，也不自动具有近优效用保证。
- 需要单一窗口时，在 \(S(x)\) 内选取最接近 \(\sqrt{W_{\mathrm{lo}}W_{\mathrm{hi}}}\) 的对数距离最近候选，记为 \(W^{\mathrm{T}}\)，并列取较小者。用于主教师检测效用的分数为 \(F(x;W^{\mathrm{T}},0)\)，而不是偏移平均分数。另行比较“取下界”“取上界”和区间内秩平均集成。
- **短序列**：所有大于等于 \(T\) 的候选合并为整条序列选项；若只剩一个候选，则无需学习窗口选择。完整块比较区域不足时，按第 4.3 节对所有候选统一使用裁剪扰动。
- **平坦或无效探针的弃权**：若 \((\max_W R_{\mathrm{patch}}(W)-\min_W R_{\mathrm{patch}}(W))/(\min_W R_{\mathrm{patch}}(W)+\epsilon_0)<\varepsilon\)，或共同有效掩码不足 2 个、误差/差异无定义，则显式设 \(S(x)=\{1,\ldots,K\}\)，并记录“无信息”状态；\(\epsilon_0\) 只是数值稳定小常数。对应诊断区间取 \([W_1,W_K]\)，不再用上界检验将其缩窄。只有这样，第 5.3 节的候选集损失才恒为零。平坦曲线也可能表示所有窗口都够用，不能直接证明探针坏了；它只是不提供下界区分信息。
- 对弃权样本仍按上述固定代表规则计算全样本教师效用，同时单独报告弃权率和有效子集结果；其任意区间命中不得算作教师可信性的证据。未满足假设的样本不会因区间非空而自动获得可靠标签。
- 容忍度 \(\varepsilon,\kappa,q_{\mathrm{top}}\) 的标定见第 6.3 节；\(q_{\mathrm{norm}}\) 默认固定，掩码比例、扰动模式及最小有效位置要求作为实现配置单独记录。

## 5. 学生：只读原始序列的窗口估计器（条件设计，未训练）

### 5.1 输入

学生只读取原始序列（全局 z-score 后），不读取 TimeRCD 的任何输出。

**序列级特征** \( \phi(x) \) ：

| 特征 | 计算方式 | 对应因素 | 参考 |
|---|---|---|---|
| \( \log T \) | 直接计算 | 截断与长度偏好 | — |
| 主周期 \( P \) 及其强度 | ACF 首个显著峰 / FFT 主频，在降采样序列上计算 | 充分性 | WSS 基准中的 ACF/FFT 方法（Ermshaus 等，2022）【核实】 |
| SuSS 窗口 | 汇总统计子序列法 | 充分性 | Ermshaus 等，2022【核实】 |
| 变点数与变点率 | PELT，在降采样序列上运行 | 同质性 | Killick 等，2012【核实】 |
| 状态切换强度 | FLUSS 弧曲线的最低点深度与个数 | 同质性 | Gharghabi 等，2017【核实】 |
| 通用形态统计 | catch22 | 综合 | Lubba 等，2019【核实】 |
| 自相似性 | 降采样序列的矩阵剖面统计（均值、分位数） | 重复模式 | — |
| 平稳性代理 | 分段均值/方差的离散度 | 同质性 | — |

**窗口相关特征** \( \psi(x,W_k) \) ：\( W_k/P \)（窗口内周期数），\( T/W_k \)（块数），\( W_k\cdot\hat{r}_{\mathrm{cp}} \)（窗口内预期变点数，其中 \( \hat{r}_{\mathrm{cp}} \) 为变点率），以及 \( W_k \ge T \) 的指示变量。

周期只是可选特征，不要求每条序列存在主周期。无显著且稳定峰值时将 \(P\) 和 \(W_k/P\) 记为缺失，并增加“周期不可用”指示；GBDT 使用缺失值机制，CNN 旁路采用固定填充值加指示变量。周期、SuSS 尺度及变点率都应换算回原始采样点单位，不能直接与降采样坐标下的 \(W_k\) 相除。

不能保证所有特征均不超过 \(O(T\log T)\)：矩阵剖面和 PELT 的成本取决于算法、子序列长度及数据。对昂贵特征使用长度上限约 4k 的降采样副本并缓存，但是否比 TimeRCD 推理便宜须在第 8.6 节实测；若成为瓶颈，则采用移除该特征的轻量版本，不预先声称开销可忽略。

### 5.2 模型

学生对每个候选窗口打分 \( u_k=h_\theta\big(\phi(x),\psi(x,W_k)\big) \) ，再做 softmax：

$$
p_\theta(k\mid x)=\frac{\exp(u_k)}{\sum_{j=1}^{K}\exp(u_j)}
$$

- **v1（首选）：** 手工特征 + GBDT（LightGBM 自定义目标）。样本量在万级，GBDT 在表格特征上稳定，也便于解释特征贡献【共识】。
- **v2：** 小型 1D-CNN。输入为降采样到固定长度（如 1024）的序列，外加 \( \log T \) 和 \( \psi \) 作为旁路标量输入。用于检验手工特征是否遗漏了信息。

这个结构是条件 logit 形式，即对 \( (x,W) \) 对打分。它与 DRNet 在主干网络前加低成本分辨率预测器的思路同类（Zhu 等，NeurIPS 2021）【核实】。

### 5.3 损失：候选集 / 部分标签损失

教师给出的是区间，不是单一标签。区间内部如何分配概率不作要求，只最大化学生落在区间内的总概率：

$$
\mathcal{L}_{\mathrm{PL}}(\theta)=-\sum_{x}\log\sum_{k\in S(x)}p_\theta(k\mid x)
$$

这是候选标签集学习的标准似然形式（Jin & Ghahramani, NIPS 2002；Cour, Sapp & Taskar, JMLR 2011）【核实】。对 logit 的梯度为

$$
\frac{\partial \ell_x}{\partial u_k}=p_k-\mathbb{1}[k\in S(x)]\,\frac{p_k}{\sum_{j\in S(x)}p_j}
$$

GBDT 实现须按同一序列的候选组共同计算 softmax 和梯度，不能将 \((x,W_k)\) 当成互相独立的二分类样本。上述损失对 logit 不保证凸。令 \(a_k=\mathbb{1}[k\in S(x)]p_k/\sum_{j\in S(x)}p_j\)，其真实对角二阶项为 \(p_k(1-p_k)-a_k(1-a_k)\)，可能为负。若 LightGBM 使用 \(p_k(1-p_k)\) 加正数下限，只能称为正曲率替代量，不能称为真实 Hessian；需通过有限差分核对梯度，并与可直接优化该损失的小型神经网络实现对照。对全候选标签的样本直接跳过，而非赋予非零替代曲率。

性质【推断】：
- 区间覆盖全部候选时损失恒为 0；第 4.4 节显式弃权才使无信息样本不提供候选集监督。
- 区间越窄，约束越强，但不代表标签越可信；错误的窄区间可能危害更大。主方法暂不引入额外置信度加权，需另行记录有效掩码数、重采样稳定性、扰动有效位置数和弃权状态。

**辅助目标（仅合成数据）：** 生成器参数（周期、状态段长度、异常重复次数）已知，可以增加一个预测这些参数的多任务头，权重为 \( \lambda_{\mathrm{aux}} \)：

$$
\mathcal{L}=\mathcal{L}_{\mathrm{PL}}+\lambda_{\mathrm{aux}}\mathcal{L}_{\mathrm{aux}}
$$

辅助目标只帮助学生学到尺度相关的表征，不替代教师，因为生成器尺度并不自动等于冻结模型的最佳窗口【推断】。多任务头用于 CNN 等可微学生；GBDT v1 默认只优化候选集目标，不假定其具有同样的辅助头。全候选标签样本在可选多任务版本中仍可能参与辅助训练，不能说其对所有损失都为零。

**可选：计算偏好。** 可比较 \(\hat{k}=\arg\max_k[\log p_\theta(k\mid x)-\gamma\log W_k]\)，主结果默认 \(\gamma=0\)。测试时不知道教师区间，因此这个惩罚不保证选择仍落在近优区间内；\(\log W\) 也只是成本代理，必须同时检查检测效用和整条序列端到端时延。是否启用作为独立实验设定确认（见第 13 节）。

### 6.4 流程

```
输入：冻结的 TimeRCD F；候选窗口 W_1..W_K；训练语料 X；超参数 ε, κ, q_top, M（固定 q_norm=0.5）
输出：学生 h_θ

S0  语料准备：收集 X，做来源重叠检查，剔除与评测集重叠的来源
S1  预处理：全局 z-score（与官方推理一致）；降采样副本供特征和 CNN 使用
S2  教师表（离线批处理，可多卡并行）
    for x in X:
        s5 ← F(x; min(5000,T), 0)                             # 仅离线定位疑似正常 patch
        分层采样锚点及 M 个 patch 掩码；固定跨窗口目标与填充噪声 # 4.2 节，保留共同有效样本
        统一确定偏移/裁剪扰动模式及共同有效时间坐标              # 4.3 节
        for W in 候选窗口:
            R_W ← 对固定锚点取长度 W 的片段，计算 patch 掩码重建误差 # 4.2 节
            for 扰动版本 in 当前序列的统一扰动集合:
                缓存该版本下的异常分数并对齐原时间坐标           # 含 o=0 官方分数
        存储 R_W、异常分数、掩码、种子、有效性与扰动模式
S3  仅在对应开发集标定 ε, κ, q_top（6.3 节）；固定 q_norm=0.5
    用锁定参数从缓存重算 δ_W、Δ_jk、W_lo、W_hi 和 S(x)，应用弃权规则
S4  特征：计算 φ(x)、ψ(x, W_k)
S5  训练学生：最小化 L_PL（+ λ_aux · L_aux），按来源分组做交叉验证选择超参数
S6  换权重时：复核训练掩码配置，重跑教师与学生；严格版本不新增目标域标注
```

## 7. 条件推理流程（无已训练学生）

```
输入：序列 x；学生 h_θ；冻结的 TimeRCD F
1. 从原始 x 得到学生所需的全局标准化副本，构造截断去重后的候选集
2. 计算 φ(x)、ψ(x, W_k)                          # 昂贵特征使用长度上限，成本实测
3. p ← softmax(h_θ(φ, ψ))；k̂ ← argmax_k p_k     # 可选：减去 γ·log W_k
4. W ← min(W_k̂, T)
5. scores ← F(x; W, 0)                           # 原始 x 交给官方 API 标准化；仅运行这一种窗口配置
输出：逐点异常分数 scores（可附带选中的窗口与 p，便于诊断）
```

### 8.2 关卡 1：余量是否存在

**目的：** 在当前锁定的官方权重、逐序列口径下确认窗口选择值得做。

定义逐序列窗口选择 oracle 增益与偏移后验增益（仅作敏感性诊断）：

$$
G_{\mathrm{oracle}}=\frac{1}{N}\sum_{i}\max_{k}U_i(W_k)-\max_{k}\frac{1}{N}\sum_{i}U_i(W_k)
$$

$$
G_{\mathrm{shift}}=\frac{1}{N}\sum_{i}\max_{o}U_i(W^{\star},o)-\frac{1}{N}\sum_{i}U_i(W^{\star},0)
$$

其中 \(U_i(W)=U(x_i,W,0)\)，主分析的 \(k\) 遍历学生实际可选的 \(\mathcal{W}_5\)。\(W^{\star}\) 是在当前分析样本、同一候选集上后验求得的最优全局固定窗口，仅用于诊断选择空间；它不同于在开发集上选定、可部署的固定基线 \(W^{\mathrm{fix}}\)。密集网格 \(\mathcal{W}_{\mathrm{eval}}\) 的 oracle 另列报告，不能用其较大的余量替代主候选集的可用余量。

\(G_{\mathrm{shift}}\) 中的 \(o\) 取 \(W^{\star}\) 的预设偏移集合。它度量只改变分块位置后可获得的后验效用增益，既可能含边界伪影，也可能含真实上下文改善，不能统称为“虚假增益”。偏移数与候选窗口数不同，最大值选择偏差亦不同，因此不把 \(G_{\mathrm{oracle}}-G_{\mathrm{shift}}\) 当作校正后的真实余量或主通过条件；将两者分别报告作敏感性诊断。裁剪扰动增益另列，不冒充同一统计量。

同时拟合两个简单回归器：只用 \( \log T \)，以及用 \( \log T \) 加主周期。用留一数据集的方式预测窗口，看它们能拿走多少余量。

**通过条件（已在 D0 合并统计前锁定）**：主候选集的 \(G_{\mathrm{oracle}}\) 的参数组内 seed 分层配对 bootstrap 95% CI 下界至少为 **0.02 VUS-PR**，且只用长度、以及长度加主周期的弱基线各自解释的余量低于 **75%**。偏移和裁剪敏感性分别报告，不以不同最大值之差作为校正阈值。实际意义阈值只在开发集上确定，查看最终 Eva 前固定；不能仅凭密集网格有余量就认定 5 个候选足够。

**不通过时：** 窗口选择余量不足，则停止“自适应窗口可带来检测收益”这一主张。是否转向问题 2 是后续独立决策，不能由本关失败直接推出。

### 8.3 关卡 2：教师是否可信

**目的：** 确认无标签教师选出的窗口接近 oracle，学生才有值得学的目标。

主教师检验的 oracle 在同一 \(\mathcal{W}_5\) 上计算，分数均取官方偏移。为避免平坦效用曲线下任取单一最优窗口造成误导，另定义真实近优索引集合：

$$
S_i^{\star}(\tau_U)
=\left\{k:W_k\in\mathcal{W}(T_i),\ U_i(W_k)\geq\max_{W_j\in\mathcal{W}(T_i)}U_i(W_j)-\tau_U\right\}
$$

\(\tau_U\) 为开发阶段锁定的绝对效用容忍度（初设 0.5 个 VUS-PR 点），不同于重建相对容忍度 \(\varepsilon\)。检查该集合是否连续，以及教师区间内每个候选的效用，而不只检查是否碰巧包含一个最优点。若真实近优集合明显不连续，单一区间标签会包含低效用间隙，这是 H1 的直接反证，不能用命中率掩盖；应将结果报告为区间表示失配，而不是事后改造标签。精确 oracle 并列时，单点统计统一取最小窗口，并把相关性只作为辅助指标。

| 检验 | 指标 | 通过条件（初设） |
|---|---|---|
| 排序一致性（辅助） | \(W^{\mathrm{T}}\) 与逐序列 oracle 窗口的 Spearman 相关，报告并列和弃权比例 | 不把效用平坦序列的低相关单独作为失败证据 |
| 区间命中 | 有信息样本上 \(S(x_i)\cap S_i^{\star}(\tau_U)\neq\varnothing\) 的比例，对比同候选数量的随机连续区间 | 显著高于随机区间 |
| 区间内部质量 | \(\lvert S(x_i)\cap S_i^{\star}(\tau_U)\rvert/\lvert S(x_i)\rvert\)，以及区间内最差候选的遗憾 | 排查宽区间命中高但夹杂低效用窗口的假象 |
| 遗憾 | \(\max_{W_k\in\mathcal{W}(T_i)}U_i(W_k)-U_i(W_i^{\mathrm{T}})\) 的均值 | 小于同样本上开发集锁定固定基线 \(W^{\mathrm{fix}}\) 的遗憾 |
| 检测效用 | 全样本教师代表窗口的官方单配置 VUS-PR | 相对锁定的 \(W^{\mathrm{fix}}\) 高约 2 点以上，配对检验显著 |
| 探针信息量 | 平坦率、弃权率、重采样区间稳定性，以及相对固定窗口的收益 | 不将“曲线不平坦”本身当作可信或正确的证明 |

**D0-dev 诊断决策（2026-11-10）**：全量 4 个 root seed、120 个锚点中 107 个有效、91 个可比较；`zero` 与 `normal_noise_0.1` 的排序相关均值为 0.412（root-seed cluster bootstrap 95% CI [0.279, 0.554]），最低误差窗口一致率为 0.462（95% CI [0.386, 0.556]）。同一 D0 seed、同一 mask 锚点、3 个噪声 seed 的 21 个共同锚点两两平均排序相关为 0.506，最佳窗口一致率为 0.571。当前版本未满足重采样稳定性的教师前置条件，故 **Gate 2 未通过，停止 v1**；尚未生成教师标签，区间质量和检测效用条件不作通过性推断。任何修订协议必须重新注册并重复 P3 诊断。

#### reconstruction probe v2 注册协议（已结束，未通过 Gate 2）

v1 的 Gate 2 结论保持不变。以下保留当时另行注册的 v2 诊断协议，不是 v1 结果的重算，也不是正式教师标签。v2 已未通过稳定性筛查，仍不读取 `mechanism-test`、生成教师表或训练学生。实现与汇总脚本分别为 `dataset_gen/src/adaptive_window_reconstruction_v2.py` 和 `dataset_gen/src/adaptive_window_reconstruction_v2_stability.py`。

v2 固定使用 W5 候选 \\(1000,2000,4000,8000,16000\\)，按序列长度截断并去重。默认窗口 \\(\\min(5000,T)\\) 的官方 `offset=0` 异常分数只用于筛选疑似正常完整 patch；重建前向使用目标居中、patch 对齐的候选片段，不等于官方整条序列的非重叠分块检测。patch 大小为 16，按 `q_norm=0.5` 保留低分候选，再将完整 patch 按时间顺序分为 4 个 strata，每个 strata 最多无放回抽取 2 个目标。一个目标 patch 在所有候选窗口上复用相同的原始位置和目标值，并且只保留对所有候选完整有效的目标，因此不再把多 patch 一次性叠加到同一个输入副本。

每个目标使用相邻 patch 均值之间的局部线性填充作为基线，并生成 5 个固定视图：基线以及两对成对的 `+noise/-noise`，噪声标准差为 0.1。目标误差按 \\(\\max(\\mathrm{MAD}(x_{patch})^2,10^{-4})\\) 归一化，先 `log1p`，再在 strata 内取均值、strata 间取中位数；输出完整误差曲线和相对最优值 10% 内的近优窗口集合。近优集合是操作性等价集合，不是置信区间。

原注册要求重复诊断至少运行三组，并覆盖两类可分离扰动：固定 fill seed 改变 target seed，以及固定 target seed 改变 fill seed；当时另列可选的 target/fill 同时变化运行。运行必须锁定同一 D0 `dev` 清单、checkpoint、候选集和协议配置。稳定性汇总只在共同有效且至少有两个候选窗口的序列上比较，报告成对排序相关、最低误差窗口一致率、近优集合 Jaccard，并同时报告每次运行的有效序列率、可选择序列率和目标 slot 覆盖率。该段仅记录旧设计，当前不新增运行；实际三次运行及其两两比较见下文。

在查看 v2 结果前锁定 Gate 2-v2 条件：每次运行有效序列率 `≥0.85`、至少两个候选窗口的序列率 `≥0.70`、目标 slot 覆盖率 `≥0.75`；共同有效序列的平均成对排序相关、最低误差窗口一致率和近优集合 Jaccard 分别 `≥0.70/0.65/0.60`。run-pair cluster bootstrap 95% CI 下界分别不得低于 `0.55/0.55/0.50`；任一指标无定义即失败。阈值不能在查看结果后调整。v2 通过后仍须单独检查教师区间的 oracle 效用和固定窗口基线，之后才可进入教师表阶段；v2 失败则归档该版本，不通过扩大教师区间掩盖失败。

**v2 首次 D0-dev 结果（未通过 Gate 2）**：同一 dev 清单共 3 次运行，形成仅变 target seed、仅变 fill seed、二者均变的 3 个两两比较；没有额外第 4 次 joint 运行。每次均为 15/15 有效、13/15 可选择，目标 slot 覆盖率均为 `0.900`。39 个比较来自同一批 13 条可选择序列 × 3 个 run-pair，并非 39 条独立序列。总体排序相关为 `0.608`、最低误差窗口一致率为 `0.641`、近优集合 Jaccard 为 `0.774`；run-pair cluster bootstrap 95% CI 分别为 `[0.400,0.946]`、`[0.462,1.000]`、`[0.662,1.000]`。target-seed pair 的排序相关/一致率为 `0.477/0.462`，fill-seed pair 为 `0.946/1.000`，joint-seed pair 为 `0.400/0.462`。因此汇总器按预注册条件判定 **Gate 2-v2 未通过**：排序相关和一致率的点估计及 CI 下界均不足；Jaccard 达标不能抵消前两项失败。产物为 `adaptive_window_runs/d0_v2_dev_stability_20261105_v2.json`。该结果仍是无标签诊断，不读取 `mechanism-test`，不生成教师标签，也不训练学生。

仅变 fill 的最佳窗口为 13/13 一致，仅变 target 与 joint 比较各为 6/13；该小样本重复使用同一 dev 清单，不能外推为填充普遍无影响或目标采样是失败的唯一原因。自动报告 `gate2_v2.passed=false` 的四项原因、原阈值和置信区间保持不变。第 4.1 节新增的训练风险不属于该次实验的已证实失败机制。当前暂停整条重建教师路线；下列消融和关卡 3 只作条件设计保留。

**教师消融**（排除"增益其实来自偏移平均这个小集成"）：

1. 只做扰动平均，窗口固定为开发集选定的 \(W^{\mathrm{fix}}\)，单列偏移与裁剪模式；
2. 只用 \( W_{\mathrm{lo}} \)；
3. 取完整教师得到的 \(W_{\mathrm{hi}}\) 作为代表（上界仍依赖下界，并非“移除下界”）；
4. 区间中点 \( W^{\mathrm{T}} \)，单次前向；
5. 区间内所有窗口分数的秩平均；
6. patch 掩码比例、随机种子及锚点采样的稳定性；连续段掩码若实施，仅作为独立探索性消融；
7. \( D \) 取 Spearman 或 top-\( q_{\mathrm{top}} \) Jaccard。

第 1 项是额外成本参照，与单窗口教师持平不证明教师增益来自集成。只有采用平均输出的教师变体获益、而第 4 项不优于固定单窗口时，才说明该变体的收益不能归因于单窗口选择；学生是否有可学习收益仍由关卡 3 判断。所有比较还须固定有效候选集合、异常分数归一化和序列后处理。

### 8.4 关卡 3：学生能否复现教师

**目的：** 回答 RQ，即只凭原始序列、单次前向能否稳定超过固定窗口。

**设定：**
- **(a) 严格设定：** 学生只在外部语料（合成数据 + 无重叠的真实语料）上训练，超参数仅在合成开发集上锁定，在 TSB-AD-U-Eva 上测试。
- **(b) 基准内无标签迁移：** 额外加入 TSB-AD-U 中其他数据集的无标签序列，按数据集/来源留一测试；不包含当前被测来源的序列。它不是使用当前测试输入训练学生的直推设定。是否采用真实 Tuning 标签标定作为另一维设定明确标注。

**指标：** VUS-PR 等检测指标；学生 top-1 落入教师区间的比例只在教师有信息样本上报告，同时给出全样本覆盖率和弃权率；相对同候选集 oracle 的遗憾；端到端推理时延。

**单次前向基线：**

| 基线 | 说明 | 来源 |
|---|---|---|
| 固定 5k | 论文主实验协议 | Lan 等，2026【核实】 |
| 开发集最优固定窗口 \(W^{\mathrm{fix}}\) | 严格版在合成开发集选，有标签标定版在 Tuning 选；不从 Eva 后验选 | — |
| 长度回归器 | 只用 \( \log T \) | 本方案 |
| 长度 + 周期回归器 | \( \log T \) 加主周期 | 本方案 |
| 周期/统计尺度启发式 | ACF/FFT 得到周期 \(P\)，SuSS 另作为统计尺度，不能统称周期；按 \(c\) 倍尺度映射到最近候选，无可靠尺度时回退固定窗口；\(c\) 按同等标签权限标定 | Ermshaus 等，2022【原方法出处，具体实现需核实】 |
| 合成效用标签学生 | 同结构学生，标签为合成数据上的 VUS-PR 最优窗口 | 摊销式模型选择，类似 MetaOD（Zhao 等，2021）【核实】 |

**额外成本参照：** K 窗口分数秩平均集成、离线教师、注入合成异常后按代理效用选窗口的方法（Goswami 等，ICLR 2023；AutoTSAD，PVLDB 2024【原方案引用，具体实现需核实】）。这些方法不是效用的数学上界；只有在同一候选集、同一输出协议下用真实标签后验选出的 oracle，才是单窗口选择的效用上界。逐数据集/逐序列 oracle 另列，不作为可部署基线。

**少标签参照**（仅当允许目标域少量标签时）：直接用这几个标签选窗口，这会是最强的竞争基线。

**学生消融：**
- 特征：只用长度 → 加周期 → 加变点/FLUSS → 全部手工特征 → 1D-CNN；
- 损失：候选集损失、以 \( W^{\mathrm{T}} \) 为硬标签的交叉熵、对 \( \log W \) 回归；
- 监督来源：教师、合成效用标签、生成器参数、教师加辅助目标；
- 训练语料：仅合成、仅真实、两者混合；
- 候选数：\(K\in\{3,5,9\}\)，预先列明具体网格；每次教师、学生和公平性对照使用同一集合。新增窗口的重建误差不能从仅有 \(\mathcal{W}_5\) 的缓存中凭空获取。

### 8.5 机制检验（受控合成数据）

用 6.2 节的生成器扫描，检验教师和学生的选择是否随结构变量按预期变化【推断，为待检验预测】：

| 控制变量 | 预期 | 检验方法 |
|---|---|---|
| 周期 \(P\) 增大 | 重建下界、检测 oracle 与学生窗口的变化；不预设 patch 重建下界必然单调 | 趋势检验并报告序列重复；若仅 oracle 变化而教师不变，说明代理假设不成立 |
| 状态段长 \(L\) 减小 | 窗口上界、检测 oracle 与学生窗口的变化 | 趋势检验；这是预期机制，不能预设窗口必然减小 |
| 异常重复次数 \(r\) 增大 | 上界是否降低及检测效用是否变化；异常重复不保证一致性规则能识别“污染” | 趋势检验并比较教师/学生/oracle；作为问题 2 线索，不当作方法已能检测污染 |

若教师与 oracle 或学生出现差异，先区分标签规则失效、结构特征不可观测和学生拟合不足；只有控制后仍显示异常密度影响参照，才作为问题 2 的证据。

### 8.6 稳健性与成本

- **扰动稳定性：** 对学生选出的窗口，分开报告各偏移和裁剪版本下的 VUS-PR，不把不同扰动当作可交换重复试验。若部署目标是官方偏移，主结论只依据 \(o=0\)；扰动结果用于敏感性诊断。
- **权重版本（可选）：** 若获取到哈希不同、来源明确的其他官方版本，再分别重测窗口扫描，观察效用曲线和窗口偏好是否改变。换权重后至少重跑教师标签并重新训练学生；“无需重训 TimeRCD”不等于“无需重训学生”。
- **长度外推：** 单独报告 16k 候选（超过预训练最大长度 10k）被选中时的表现。
- **成本：** 报告特征计算时间、学生推理时间、TimeRCD 前向时间，以及与固定 5k、K 窗口集成的端到端时延和显存对比。

## 9. 推翻条件

以下任一成立，即认为本方向的当前方法版本未通过预设检验；应修改或停止该版本，而不是直接把失败归因于问题 2：

1. **关卡 1：** 主候选集的逐序列选择余量接近零，或仅出现在无法匹配偏移的诊断子集；长度/统计尺度基线已取得同等收益。
2. **关卡 2：** patch 掩码探针大比例弃权/重采样不稳定；或教师区间覆盖大量低效用候选，单窗口教师效用/遗憾不优于开发集锁定固定窗口。若有效信号只出现在未对齐预训练分布的掩码配置，主探针不成立。
3. **关卡 3：** 学生相对最强、同等标签权限的单窗口官方配置基线，其增益区间上限低于预设的最小实际意义阈值，视为未达到研究目标；若区间同时覆盖零和实际意义阈值，则结论是不确定而非已证伪。不能仅因 p 值不显著就断言“相同”，应报告置信区间。

阈值在查看最终评测任何一关的标签结果前固定，避免事后调整；开发过程和最终确认结果分开记录。

## 10. 风险与自我反驳

| 风险 | 表现 | 应对 |
|---|---|---|
| 重建代理与检测效用不一致 | 重建偏好未必对应异常头的窗口效用，尚无独立支持 | 暂停教师；不靠调掩码维持假设，不自动换用注入—恢复代理；新路线须另立协议 |
| 异常位置也参与遮挡与联合监督 | 原训练可能要求从缺少关键信息的输入恢复异常原值并分类 | 记为方法风险；不推定损失必然冲突，不用它解释 v1/v2 的稳定性失败 |
| 一致性检验把"有益变化"误判为偏差 | \( W_{\mathrm{hi}} \) 系统性偏小，在 UCR、Power 这类偏好大窗口的数据上明显 | 单独报告这些数据集；调节 \( \kappa \)；比较只用 \( W_{\mathrm{lo}} \) 的消融 |
| 学生无法复现教师 | 教师在结构近似序列上输出不同区间，学生却塌缩 | 分解教师噪声、特征不可观测、训练分布偏移与学生优化失败；不得直接归因于异常污染 |
| 上界不是污染指标 | 一致性截断与 oracle 效用/高异常密度趋势不符 | 只称尺度敏感性启发式；去掉污染解释或停止该上界规则 |
| 学生塌缩到众数窗口 | 学生对几乎所有序列输出同一窗口，效果接近开发集固定窗口 | 检查预测窗口分布与教师区间分布；分解 H2、标签噪声、跨来源偏移与优化失败 |
| 增益来自小数据集 | 逐数据集平均有增益，逐序列平均没有 | 两种口径都报告，以逐序列为主 |
| 训练语料与评测来源重叠 | 零样本说法不成立 | 来源审计；严格设定只用合成数据加经过审计的真实语料 |
| 掩码分布或单位与预训练不一致 | 重建误差偏大或不稳定，窗口排序对掩码设置敏感 | 核实预训练 patch 单位与 mask 实现；对比例、填充值及随机种子做敏感性分析 |

**最可能出错的地方【推断】：** 两个代理环节都可能失败：局部 patch 重建的窗口偏好未必等于异常检测偏好；即使教师区间接近 oracle，异常污染带来的上界变化也未必能从结构特征预测。出现“教师好、学生差”只能说明当前学生未复现标签，不能单独证明异常内容是原因。

## 11. 定位与审稿质疑

### 11.1 定位

本工作属于摊销式模型选择，加上非参数带宽选择方法向时序基础模型推理配置的跨域移植，再加经验性改进【推断】。贡献等级不宜夸大。

### 11.2 原拟增量（均未形成已验证贡献）

1. **无需异常标签的元标签：** 原拟通过冻结模型的 patch 重建代理和跨窗口一致性生成；该教师路线现已暂停，没有正式元标签，不声称能指导检测窗口。来源审计和可调用性均不足以证明效用。
2. **区间目标：** 用候选集损失表达教师不确定范围；它有望避免强行指定单点，但是否比单点标签更稳健、区间是否近优都需要实验检验。
3. **可证伪的研究问题：** 冻结 TimeRCD 的窗口偏好能否从序列结构预测，并用受控合成数据检验机制。

在检索范围内，没有找到针对 TSAD 基础模型逐序列上下文窗口估计的直接先例；检索有限，投稿前需要系统检索【需核实】。

### 11.3 预期质疑与回答

**质疑 1："这不就是 MetaOD 式的元学习模型选择，只是换了标签来源？"**
承认属于这一类。MetaOD（Zhao, Rossi & Akoglu, NeurIPS 2021）依赖历史基准上的有标签性能【核实】。本方案的元标签不需要异常标签，且目标是同一模型沿一个有序参数的区间，所以适用的语料范围和换权重时的维护成本都不同。

**质疑 2："Ma 等（SIGKDD Explorations 2023）表明无监督的内部评估策略在异常检测模型选择上与随机选择相当。"**
该研究的任务数、模型数和原文结论须在正式写作前按原文复核【需核实】。本方案拟考察同一冻结模型的有序窗口参数，但分块扰动尺度不应称为统计噪声尺度或理论校正。关卡 2 用同候选集 oracle 检验教师；若教师失败，不能用“问题更窄”回避。

**质疑 3："为什么不直接做 K 窗口集成？"**
集成需要 K 次前向，与单次前向的约束冲突。集成作为不计成本的参照报告；若学生不如集成而集成稳定优于固定窗口，结论就是"在成本允许时用集成"。

**质疑 4："论文说重建头在推理时完全丢弃，为什么还用它？"**
原设计只在离线探针使用，但这不足以回答其适用性。辅助重建训练有收益不表示冻结重建误差能选检测窗口；原任务还包含异常位置的重建目标。当前缺少代理效用证据，v1/v2 也未通过稳定性筛查，因此已暂停该教师路线。

**质疑 5："学生可能只学到长序列用大窗口。"**
长度回归器和长度加周期回归器都是基线；赢不了它们即判失败（第 9 节）。

**质疑 6："用 Tuning 划分标定超参数，还算零样本吗？"**
同时报告只在合成数据上标定的版本；Tuning 划分是 TSB-AD 协议提供的调参集合，按其规则使用并在文中说明。

**相关但不采用的方案：**

| 方案 | 不采用的理由 |
|---|---|
| Adaptive Attention Span（Sukhbaatar 等，ACL 2019） | 需要训练时学习距离掩码；冻结的 TimeRCD 没有见过这种掩码【推断】 |
| 用注意力距离估计所需上下文（参考 Dosovitskiy 等，ICLR 2021 的平均注意力距离） | 注意力权重不能直接说明模型用了什么（Jain & Wallace, NAACL 2019）【核实】；也区分不了有用的长程依赖和"twin freak"式的重复异常吸收（MERLIN, Nakamura 等，ICDM 2020）【推断】 |
| 置信度 / 熵最小化选窗口 | 会偏向把异常吸收进参照、分数被压平的窗口，与问题 2 冲突【推断】 |
| 推理时直接运行教师规则 | 需要默认窗口探测、候选窗口下的重建探针及扰动推理；实际成本按实测报告，不预设一定比 K 窗口集成贵 |
| 动态 patch / 实例自适应位置编码（Kairos, arXiv 2509.25826） | 需要重新训练基础模型，超出本方案范围；可作为相关工作讨论【核实：方法描述】 |

## 12. 成本估计

以下保留原设计的粗估【推断】，不是已批准预算；路线暂停期间不新增计时或训练。现有耗时数字不能从表格直接外推到完整教师流程：

- **教师：** 默认 \(K=5,M=4\) 时，标称流程为 1 次默认窗口探测、15 次整条序列的扰动配置推理（偏移或裁剪）、20 次单片段掩码重建，合计 36 项评估任务，而非 36 个等成本的底层网络调用。长序列分块、batch size、短序列合并、无效样本及敏感性重复会改变实际调用数。不能用 Table 16 线性推算 2 万点序列或 1 万条语料耗时，原“4–10 秒/序列、10–30 GPU 小时”未获验证，需基准测试替换，不作为预算承诺。
- **合成效用标签（仅基线和验证使用）：** 1 万条合成序列约 3–4 GPU 小时。
- **评测前向表：** 每条序列的密集网格官方分数用于 oracle；主候选的扰动分数及 patch 重建用于教师诊断，额外的密集网格扰动只在预注册子集计算。缓存内容及各部分成本分列，不能用只含官方分数的表声称已经完成教师评估。
- **学生训练：** GBDT 在 CPU 上为分钟级；1D-CNN 在单卡上为小时级以内。
- **推理增量：** 特征计算加学生前向，预计在毫秒到百毫秒级，需与 TimeRCD 单次前向对比实测。

## 13. 不确定性与待确认事项

**已核实与仍待确认的事项（不自动启动实验）：**
- checkpoint 含重建头，配置及 embedding 输入宽度为 16，strict load 已通过；这只证明实现可用。
- 历史完整入口使用零填充、15% 随机 patch 遮挡，启动时将共享 patch size 设为 16；当前辅助函数使用噪声填充。checkpoint 未记录训练 commit/fill，确切训练快照仍无法确认，不能从默认值 4 推定训练不匹配。
- 正常 patch 筛选、掩码采样覆盖及固定目标设置是否造成严重偏差；对随机种子、锚点、掩码比例的教师标签稳定性。
- patch 重建误差与检测窗口效用是否存在可重复关联；该代理假设若不成立则下界规则停止。
- 一致性启发式、裁剪替代扰动与近优区间质量的对应关系；Lepski/ICI 理论保证不直接适用于本任务。
- LightGBM 候选组目标的梯度实现/有限差分、二阶近似和全候选弃权行为。
- 完整教师和推理端到端耗时、窗口改变对块数和总运行时的影响。
- 新候选扩展、密集 oracle 与短序列截断后的实际有效类别数和评估覆盖。
- 当前锁定的官方权重下，逐序列窗口敏感性与余量大小。
- LOTSA 等外部语料与 TSB-AD 评测来源的重叠情况。
- `TSB-AD-U-Tuning.csv` 与 `TSB-AD-U-Eva.csv` 是否不相交。
- 如开展历史版本对照，确认不同权重的来源、哈希及对应论文版本；当前不预设存在另一套“论文旧权重”。
- arXiv 页面上的撤稿说明（引用时以 ICML 2026 版本为准）。
- 是否存在直接相关的先前工作（需系统检索）。

**需要你确认的设定：**
1. 本方案默认以严格无目标域标签为主设定，TSB-AD Tuning 标定仅作单列版本。若研究目标实际是目标域少样本适配，还需明确标签预算，并加入相同预算下直接用标签选窗口的基线。
2. 先做单变量，还是同时做多变量？多变量下 token 数随通道数增长，窗口的计算代价与选择逻辑都会变化。
3. 在单次前向之外，是否要求在近优区间内优先选小窗口以节省计算（5.3 节的 \( \gamma \) 项）？
