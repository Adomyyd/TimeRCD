# 阶段一真实基准序列诊断：2026-11-04

## 配置与范围

- 冻结清单：[selection.json](../selections/stage1_real_v1/selection.json)；配置：[config.json](../selections/stage1_real_v1/config.json)。
- 24 条 TSB-AD-U 开发诊断序列，9 个来源；异常占比低／中／高各 8 条。TSB-AD-U 含人工合成数据，本批不能统称为物理真实采集数据。
- 候选限于已有 700 条评测元数据，筛选后 531 条有效候选，测试段长度 256–20000。按来源、长度、末窗状态、异常占比分层，不使用模型成绩选择样本。
- 官方单变量权重，Patch=16；窗口 128、256、512、5000，共 96 组。随机种子 2024，batch=1，GPU 2（RTX 3080 Ti），float32，TF32 关闭，启用确定性算法。
- 主指标为概率分数的 Average Precision（AP），补充 logits 的 AP 和 ROC-AUC。AP 不是原评测代码 PR 曲线梯形面积。

## 结果

### 1. 推理路径与数值检查

- 96 组公共 API 与旧评测后端的概率和 logits 完全一致。
- 96 组独立尾窗与原推理尾部完全一致；`tail_replay` 对照的指标变化为 0。
- 96 组尾窗零补齐与 compact 输入均在原容差内一致。
- 8 组短序列强制零补齐中，1 组 logits 超过原容差。因此主运行保留 **`checks_failed`（95/96 组通过）**，没有调整容差重新判为通过。

失败项为 `294_TODS_id_8_Synthetic_tr_500_1st_200`、窗口 5000、有效长度 4500。GPU float32 最大概率差为 4.20e-6，最大 logit 差为 2.91e-5；AP、ROC-AUC 基本不变。

对同一输入和权重进行 CPU 数值复核：float32 最大 logit 差为 1.91e-5，仍不通过原检查；将同一模型和输入转换为 float64 后，最大 logit 差降至 **7.64e-14**，概率差为 **1.73e-14**，AP、ROC-AUC 差均为 0。这支持该失败属于 float32 数值舍入，而非零补齐改变了有效信息通路；原始失败记录仍然保留。

### 2. 补齐是否改变完整序列的检测指标

zero/compact 只替换末窗分数，之前窗口的分数不变；没有外层补齐时为 no-op。下表统计概率 AP，差值为干预减当前基线。

| 条件 | 组数 | 平均绝对 ΔAP | 最大绝对 ΔAP | 改善超过 0.01 | 恶化超过 0.01 |
|---|---:|---:|---:|---:|---:|
| 尾窗零补齐 | 96 | 0.000758 | 0.020613 | 1 | 0 |
| 尾窗仅有效点（compact） | 96 | 0.000758 | 0.020613 | 1 | 0 |
| 短序列强制零补齐 | 8 | 0.000003 | 0.000027 | 0 | 0 |
| 短序列强制末值补齐 | 8 | 0.001829 | 0.007664 | 0 | 0 |

0.01 是推理前记录的描述性 AP 变化阈值，不是统计显著性标准。AP 用 0–1 标度，0.020613 对应约 2.06 个百分点。

最大尾窗改善来自 `479_UCR_id_177_Medical_tr_2000_1st_7000`、窗口 5000：测试段 6000 点，末窗有效长度 1000，含 50 个异常点；零补齐的 AP 增加 0.020613，ROC-AUC 增加 0.001587。另一较明显变化是 NEK 短序列在 256/512 窗口下 AP 分别增加约 0.00925/0.00869。

### 3. 补齐能否解释窗口敏感性

当前基线在这批序列上的宏平均指标：

| 窗口 | AP | ROC-AUC |
|---:|---:|---:|
| 128 | 0.209141 | 0.624189 |
| 256 | 0.277229 | 0.668590 |
| 512 | 0.391077 | 0.751992 |
| 5000 | 0.505597 | 0.843596 |

逐序列计算四个窗口的 AP 最大值减最小值：

- 当前补齐的平均范围：**0.391322**；zero/compact 后：**0.392158**。
- 两种条件下，24 条序列的范围均超过 0.01；没有序列因 compact 干预使范围缩小超过 0.01。
- compact 减当前的范围差：均值 **+0.000835**，按序列 bootstrap 的 95% 区间为 **[-0.000331, +0.002709]**。
- 对 16 条长度至少 5000 的序列，当前平均范围 **0.293640**，compact 后 **0.295142**。差异不只出现在短序列。
- 最佳窗口的分布为 5000：16 条，512：6 条，256：2 条；compact 后最佳窗口没有变化。这里的最佳窗口使用开发标签事后计算，仅用于描述敏感性。
- logits 的长序列平均范围约从 0.293598 变为 0.295100，与概率分数结论相符。

## 结果范围与限制

**在这批开发诊断序列和四个窗口范围内，尾部补齐会改变部分分数，个别序列指标也会变化；但它不足以解释主要窗口差异。**正确掩码下增加全无效 Patch 的影响接近数值误差，没有观察到由此产生大幅性能下降的证据。

这还不能证明参照污染、自适应窗口或多尺度的必要性。5000 点固定窗口在本批宏平均表现最好。5000 不是 16 的整数倍，本轮没有改变完整中间窗口的 Patch 边界补齐，也没有移动分窗起点；“所有实现因素均已排除”仍不成立。
