# E07：最后一层干净反事实参照替换（2026-11-05）

## 主要结论

**干净参照替换没有带来普遍改善。** 在预定长事件集合上，仅替换V提高P异常—N正常条件AUC，但降低完整序列AP；再替换K并重算权重，相对V改善，却未恢复到原模型AP。形态、事件长度和对齐条件之间有明显方向差异。

全层P_C的整体AP效应为正，未在整体上复现开发基准的负方向；但部分预定子条件确有退化。下一步应先控制对齐实验中共同变化的**背景相位与M/P覆盖、删除数量**，并在匹配条件下比较层范围，不能直接根据整体平均扩展到全层干净替换或训练模块。

## 设计与实际执行

- [执行前协议](../protocols/stage2_clean_reference_v1.md)、[配置](../configs/stage2_clean_reference_v1.json)。
- [运行目录](../runs/20261105T011950_160522Z_stage2_clean_reference_v1_4bdb5253/)，状态`completed`。
- `RCD_yyd`，GPU 2（运行前15 MiB、0%利用率），官方冻结单变量权重，确定性float32、TF32关闭、batch1。
- 8个生成种子3101–3108；每种子同一周期64正弦加噪声底图，长度5000。固定640异常点、绝对扰动幅度4，正偏移、负偏移、逐点交替±4三种形态；事件长度5/32/128，对齐偏移0/8。共144条新输入，其中96条长事件用于主统计、48条短事件用于P空集合对照。
- 两分支共享异常输入的官方整序列均值/标准差；干净分支提供最后一层投影后的V和RoPE后的K。其含义是共享尺度的受控反事实，不是单独按干净统计量归一化的部署输入。
- A原模型；C最后一层P硬屏蔽且保留自身；V保持异常Q/K及权重，仅替换读取P的非对角边V；KV在同一边集合替换K/V并重算权重；C_all为全层P_C桥接条件。KV保留对角logit和原V，但对角概率可随softmax分母变化。
- 先完成12例预定gate及27条旧合成回归，再执行144×5=720条正式条件预测。720不包含gate、旧数据回归、干净分支和数值验收调用。
- 概率为主、logits辅助；先在每个生成种子内平均形态/长度/对齐，再按8个种子bootstrap（seed2024、10000次）。以下95%区间均为描述性、未经多重比较校正；仅反映固定生成机制的噪声种子变化，不覆盖真实数据来源不确定性。

## 验收与失败记录

- 首次55项测试中54项通过，1项因既有数值差函数不支持布尔减法而失败。仅修复本轮检查适配层，将布尔掩码转为0/1整数按零容差比较；未改变协议或数值容差，修复发生在官方权重运行前。
- 修复后55项测试全部通过（本轮新增7项）：逐边手算V/KV、对角保留、padding、权重固定、原内容回填、空选择、共享尺度、固定异常量/能量、种子配对、小模型端到端与异常恢复。
- 正式检查3984项、gate 396项、旧27条回归432项，共**4812项全部通过**。
- 最大绝对误差：正式`1.1444e−5`、gate `7.8678e−6`、回归`1.7643e−5`。采用执行前固定的`atol=1e−5, rtol=1e−5`联合准则，不能把“通过”写成所有绝对差都小于1e−5。显式softmax与原SDPA存在有限精度差，未调整容差。
- V权重、最后一层原输入/Q/K/V、KV未替换logit及对角logit、原内容回填与显式空选择均通过预定零容差检查；旧输入/父分数回归使用上述联合容差。短事件P为空，V/KV/C为无操作；C_all经旧适配器与官方路径按数值容差核对。
- 输入/覆盖在模型调用前保存；59个读取的父文件执行前后哈希一致。模型参数/缓冲区SHA256仍为`46c5ba55203d759a4f46a92f971ba84a92a7243ab919f1e696bfc895ced0edcf`。
- 正式运行无失败或中断，无训练、无权重修改。执行范围与预定协议一致。

## 下一步：先控制混杂，再决定层范围扩展

1. **先制定对齐/相位/覆盖解耦协议。** 目前0→8同时改变背景相位、M/P数量和被删除参照数量；新设计须预定独立背景相位因素，并加入固定目标P数量/位置规则的对照，避免只对负结果加实验。
2. 覆盖本轮完整三形态及32/128长度，不仅挑选最差子条件。沿用A、last-C、all-C，主比较固定为层范围×对齐/覆盖交互，报告绝对AP及P/M/N点组排序，先确认损失是否在控制后稳定出现。
3. 在机制解释前，利用本轮已保存输出另立离线高分区排序协议，解释AP与AUC反向及基线接近上限的影响；不能把本轮尚未计算的高分区损失写成已验证结论。
4. 只有稳定复现目标损失并厘清层范围后，再考虑匹配层范围的干净参照替换；当前不直接推进全层替换或可靠性头。
