# 冻结表示上的成对分类探针（2026-11-21）

检验 P1 的检测下降是否来自表示变差。两个骨干（稳定版 P0/P1 的 best）全部冻结，只在完整观测表示上训练同结构的两层分类头，比较表示里可读出的异常信息量。

## 方法

- 骨干冻结；头为 `256→128→1`，GELU，AdamW 1e-3、15 轮，逐点二分类。
- 每个骨干用种子 127/128/129 各训一个头，数据、预算和批顺序一致。
- `original` 指各 run 自带的 `anomaly_head`；其余键是在该骨干上重训的探针头。
- 评价集合：合成留出 512 条、真实 700 条（AP 与 recall 有效 694 条）、合成平台数据；AP、recall、FPR 用配对 bootstrap 给 95% 区间。

## 结果

真实数据 AP 差值（P1 头 − P0 头，百分点）：种子 127/128/129 为 +4.16/+3.83/+3.77，`original` 为 −0.53；recall 为 +6.15/+3.28/+3.96，`original` 为 −1.10；FPR 为 −0.14/−0.14/−0.15，`original` 为 −0.12。

合成数据 AP 差值为 +2.67/+1.64/+2.55，`original` 为 −3.10。平台 `event` 带为 +5.14/+0.62/+4.72，`original` 为 −2.03。

同一骨干上重训的探针头在 P1 表示上稳定更好，说明下降不完全是表示问题；但直接用各自原头时 P1 反而更低，指向训练出的分类头与训练/推理通路。

## 文件

| 文件 | 内容 |
|---|---|
| `probe.py` | 探针脚本，在实验主机上从本目录运行 |
| `design.json` | 训练/验证序列索引与平台事件清单 |
| `p0_heads.pt`、`p1_heads.pt` | 各骨干三个种子的头权重与标准化参数 |
| `synthetic.json`、`real.json`、`platform.json` | 汇总与配对区间 |
| `*_rows.json.gz` | 逐序列明细，已 gzip，读取前先解压 |

依赖两个稳定 run 的 `best.pth` 与 400k 数据；只做前向和头部训练，不改动原权重。
