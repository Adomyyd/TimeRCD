# 配对上下文消融（2026-11-21）

在固定目标点与冻结读出上替换目标周围的上下文，检验 P1 的差异是否来自更会利用上下文。

## 方法

- 每条合格序列取窗口内的异常点，并取一个正常点作配对；目标点本身始终可见。
- 三种条件：`baseline` 不扰动；`near` 遮挡与目标相距 1 个 patch 的块；`far` 遮挡相距 9 个 patch 的块。
- 对每个目标点计算 `far − near` 的分数差，再取 P1 与 P0 的差（双重差分），用配对 bootstrap 给 95% 区间。
- 读出两套：各 run 自带的 `anomaly_head`（`original`）和冻结骨干上重训的探针头（`probe127`），骨干均为稳定版 best。
- 合格序列：合成 492/512，真实 667/700；其余因窗口不足跳过，清单在 JSON 的 `skipped`。

## 结果

真实数据 `original` 头，异常点上 `far − near` 的 P1−P0 差：分数 −0.0075（区间含 0），窗口内百分位 −0.0122（区间不含 0）。`probe127` 头的百分位差为 −0.0184（区间不含 0）。正常点上百分位差为 +0.0575（区间不含 0）。

即 P1 的读出在异常点对上下文距离更不敏感、在正常点更敏感，方向与“更会利用上下文区分异常”相反。合成数据上同类差值更小且多数区间含 0。该探针只测固定点上的响应，不能替代端到端检测结论。
