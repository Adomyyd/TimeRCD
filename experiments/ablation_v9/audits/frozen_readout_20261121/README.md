# 冻结编码器的小型读出探针（2026-11-21）

检验冻结表示对正常/异常点的重构可预测性。编码器冻结，只训练一个小型读出层，在相同遮挡和目标上比较 P0/P1 的 MSE。

## 方法

- 两个骨干冻结；读出层结构相同，训练集为 2048 条合成序列、262,144 点（其中异常 14,296 点），留出 512 条。
- 训练遮挡与验证遮挡分别用种子 72 和 `validation_mask_seed`；目标为遮挡位置的配对正常值 \(X^0\)，并按该点标签分组。
- 报告全部点、正常点和异常点的 MSE，并按序列配对给 95% 区间与胜场数。

## 结果

| 子集 | 点数 | P0 | P1 | P1 胜出序列 |
|---|---:|---:|---:|---:|
| 全部 | 293,117 | 0.1487 | 0.0381 | 507/512 |
| 正常 | 277,544 | 0.1350 | 0.0347 | 505/512 |
| 异常 | 15,573 | 0.3927 | 0.0981 | — |

三个子集的配对区间均不含 0。异常子集覆盖 347 条序列。结论是 P1 表示更接近可预测的正常/观测结构，但这与检测成绩下降并存，说明“重构更好”不能直接推出“检测更好”。
