## 3. 量级核验：标准化放大型解释不足

标准化与损失（src/data.py collate、src/losses.py masked_mse）：

```
mu_B    = 整批所有样本所有时间点的均值（每通道一个标量）
sigma_B = 同范围的标准差
z       = (x - mu_B) / (sigma_B + 1e-4)
L_recon = M 上所有点 (z_hat - z)^2 的均值
```

因为 sigma_B 来自同一批数据，有恒等式 sum_i (x_i - mu_B)^2 = (N-1) * sigma_B^2，故

```
|x_i - mu_B| <= sqrt(N) * sigma_B   =>   |z_i| <= sqrt(N)   =>   单批 L_recon <= N
```

代入本数据：N = 32 * 3940 ≈ 1.26e5（最长批约 3.2e5），单批对**整轮均值**的贡献上限只有 N/11875 ≈ 10.6（典型）至 27（最长）。

而 epoch1 均值 2908.19 对应总额 2908.19 * 11875 ≈ 3.45e7，需要 108-274 个批次同时顶在该上界；1% 的日志采样本应命中 2-3 个，实测最大值只有 9.72。

**因此：“按批标准化分母塌缩”能解释温和抬升（后半轮 0.9-1.0 那一段），解释不了 2908 这个量级。** 超出上界的部分只能来自**预测侧**（模型输出），或说明本文对某处代码路径的理解仍有缺口。两种可能均未排除，根因**未定**。

不要据此认定：不是padding直接导致；不是分类项；不是数据错误（未复核原始pickle）；不是浮点溢出。

## 4. 尚未实现的判别手段

逐batch触发记录至今未实现（实验记录.md第6节第1项）。需记4个量即可一刀切开：

| 记录项 | 判别规则 |
|---|---|
| 该批 N、M 点数 | — |
| max abs(z)（标准化目标） | 若 > sqrt(N)，本页第3节推导有误 |
| max abs(z_hat)（标准化预测） | 若远大于 sqrt(N)，问题在模型输出 |
| 该批 recon loss | 若 > N，定性为预测侧，与标准化无关 |

判据不依赖数据分布假设。

## 5. 与官方/论文公式的对应

| | 重构项 | 分类项 |
|---|---|---|
| 论文主文 | lambda * || M * (X_rec - X) ||_2^2（求和） | BCE |
| 论文附录C.4 | MSE(x_hat_t, x_t)（无mask） | CrossEntropy |
| 官方training.py | F.mse_loss(pred[mask], x[mask])（均值） | F.cross_entropy |
| v9 losses.py | values.square().mean()，values=(pred-target)[mask] | 同 |

v9-P0与官方代码**逐式一致**（含official分支复现的二值化padding行为）；与论文有三处不一致（求和/均值、BCE/CE、附录漏mask）。论文只说输入是normalized，**没有给出跨整批统计与+1e-4这一细节**，因此该式的权威定义只能取官方training.py。
