## 7. 来源、协议与比较边界

论文来源：[本地论文 PDF](<../../Lan 等 - 2026 - Towards Foundation Models for Zero-Shot Time Series Anomaly Detection Leveraging Synthetic Data and.pdf>)，第 7 页 Table 1（11 个单变量数据集）、第 23 页 Table 8；[arXiv](https://arxiv.org/abs/2509.21190) 作为外部入口。本表数值以仓库内 PDF 为准，外部版本可能更新。

论文 Table 2 的“0.878 / 0.569 / 0.523 / 0.478”属于第 3.4 节的 350M 点训练数据对照，不是本报告 Table 1 主模型的整体分数，未将其混入主表。论文附录 E.4 的 Table 12 仅覆盖 9 个单变量数据集，且是另一项数据规模实验，也不替代本报告的 11 组对照。

| 实验 | 训练来源 | 训练种子 | best epoch（从0开始） | 结果来源 |
| --- | --- | ---: | ---: | --- |
| TimeRCD 论文 | 论文描述的 2.5B 点合成预训练；本报告未重测官方权重 | — | — | 本地 PDF Table 1 |
| P0 official | 当前 400k 单变量样本，official 分类 padding | 72 | 31 | [评测 run](runs/p0_official_dp_20261111_003608_eval_20261114_restart2_s200_r700/) |
| P0 ignore | 当前 400k 单变量样本，忽略分类 padding | 72 | 26 | [评测 run](runs/p0_ignore_dp_20261112_170107_eval_20261114_restart2_s200_r700/) |

两个 P0 共同设置：总 batch32、length_bucket、bucket_multiplier50、DataParallel、模型 patch16、遮挡块16、遮挡比例0.15，各自按同一验证规则选择 best。两组训练配置差异限于分类 padding 策略，但实际早停轮数与 best epoch 不同；这是单个训练种子的初步对照，不能代替多种子结论。论文与当前训练数据、规模及实现流程并非严格相同，论文差距不能单独归因于 padding。

本次评测共用 [eval_official.json](configs/eval_official.json)：官方实现版本 `d458549f6962029a5c5241c43a5baa1ec5eccbb2`，推理窗口5000、batch64、seed2024、fast 指标、F1-T 分位点800。真实数据沿用官方 dropna、文件名训练边界及测试后缀；逐序列计算，不拼接多条序列计算指标。部分 F1 指标沿用官方在测试标签上搜索阈值的口径，不能当作部署时固定阈值的性能。

完成与一致性核查：两组 `status.json` 均为 completed；各有1800行（合成200×2分数＋真实700×2分数），无重复键；行顺序及序列元数据一致；合成索引摘要、全部真实文件清单及摘要、评测协议、源代码摘要和依赖版本一致；本表汇总与原始 CSV 均值核对通过。ignore 于16:30:45、official 于18:08:30完成（UTC+8）。

NaN 沿用官方返回值，不替换为0；汇总只对对应指标的有限值求均值。真实数据 AUC-ROC 两组均有694/700条有效，另外6条测试后缀没有异常标签；Affiliation-P 在 ignore 的 probability 下为698/700条有效（NAB、WSD各缺1条），ignore logit 及 official 两种分数均为700/700。其余真实指标与合成指标均完整；11组宏均值的每项指标均有11组有效。主表的四项指标在两组均为700/700条有效。

原始产物均位于上表评测 run 的 `metrics/`：

- `eval.json`：各域、各分数的精确汇总及 `valid_metric_counts`。
- `group_mean_metrics.csv`：11个数据集分项。
- `domain_summary.csv`：序列等权和数据集等权汇总。
- `per_series.csv`：逐序列、逐分数的全部16项指标。
- run 根目录的 `evaluation_manifest.json`：权重、数据、协议和源码摘要。

## 8. 后续追加规则

完成一个新实验后，在第1节主表及第2节四张分项表的最后添加一行；需要跟踪合成、序列平均或 logit 时，在对应表同样追加该实验一行。固定使用本表已注明的域、分数和汇总方式，不改写旧基线，不把论文缺失项补成0。第7节同时追加该实验的种子、best epoch和结果链接。

正式加入表格前，核对 run 已 completed、样本数/索引/真实文件及协议一致；有子集、不同训练预算、不同种子或 NaN 分母时注明。数值从 `metrics/eval.json` 读取后乘100并保留两位小数，不从训练 loss、训练期验证 F1 或控制台截断值代填。主表字段固定为 `real → probability → group_macro`；分项固定为同一分支的 `group_means`。
