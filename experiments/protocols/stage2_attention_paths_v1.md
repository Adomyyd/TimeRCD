# 注意力连接消融：执行前协议 v1

状态：设计已记录，尚未实现或执行。已有数据已被分析，本轮属于开发集上的假设驱动后续诊断，不是独立确认性验证。后续修改需记录版本、修改原因以及是否已查看新结果。

## 1. 目标与可识别范围

主要问题：在当前冻结模型、5000 点窗口和既定输入下，保留被选 Patch 的自身注意力连接，能否缓解全列硬屏蔽造成的退化？

这里只识别连接干预的条件效应。删除连接会重新归一化 softmax；恢复连接也恢复一份参照及其注意力质量，不能把差值解释成与数量、注意力竞争完全分离的“自身语义价值”。不由此直接决定可靠性头、软权重或训练适配是否有效。

## 2. 精确定义连接方向

固定一个窗口，V 为有效 Patch 集，S 为选中屏蔽的 Patch 集，S 是 V 的子集。行 i 是 query，列 j 是 key/value；允许 (i,j) 表示查询 i 可以读取参照 j。原模型允许所有有效 key；padding key 始终禁止。

对有效查询定义：

| 条件 | 从原模型中删除的连接 |
|---|---|
| A 原模型 | 无 |
| B 只删除选中 Patch 自身连接 | j 属于 S 且 i=j |
| C 只禁止选中 Patch 被其他位置读取 | j 属于 S 且 i≠j |
| D 删除选中 Patch 的整列 | j 属于 S |

S 的标签版本为含任一异常有效点的 Patch，混合 Patch 一并入选。随机版本从有效 Patch 中均匀抽取同样数量，不使用异常位置选择成员。标签与随机两种 S 各自复用到 B/C/D 以及两种层范围。

这里的自身是整个 Patch，不是单个原始时间点。所有条件均保留输入、Patch embedding、query、残差、位置及输出；只改变允许读取的连接。

无效查询不计分，且永远不能作为有效 key；不恢复它们的对角线。具体实现必须保证其行为不影响有效查询，禁止为修复空行而打开 padding key。

### 对先前传播描述的修正

当 C 从第一层到最后一层使用同一个 S 时，V\S 的查询始终不能读取 S。当前模型的 Patch embedding、归一化层、MLP 和检测头在 token 之间不混合，因此在固定预处理后，S 的输入扰动不能经注意力传播到 V\S。保留 S 的自身连接不会自动产生向其他 Patch 的跨层泄漏；先前相反的说法不准确。

C 的 S 位置仍保留自身内容，混合 Patch 内也有异常信息，所以不能称为“所有查询均只读取干净参照”。整序列输入标准化的跨点依赖仍存在。本协议的信息路径测试在标准化之后施加扰动。

## 3. 层范围与主要对比

- last：只干预最后一层。进入该层的输入及 Q/K/V 必须与 A 一致，检验同一组表示上的连接改变；前层已传播的信息未被消除。
- all：每层使用同一个连接规则和 S，检验表示逐层改变后的总效应。

主分析为基准序列 all 条件下的两个成对差：

1. 自身连接恢复效应：AP(C)−AP(D)。
2. 标签与数量匹配随机的恢复效应差：上述差值的标签版本减去五个随机版本差值的均值。

必须同时报告 AP(C)−AP(A)，防止把“比 D 少退化”当成“优于原模型”。last 条件重复上述比较，作为路径定位。辅助报告 AP(B)−AP(A)、AP(D)−AP(B) 以及交互差 AP(D)−AP(C)−AP(B)+AP(A)。交互差是非线性指标上的操作性描述，不等于生物或算法机制协同。

随机对照匹配每种条件的删除连接数，但不匹配标签位置的空间结构、内容或原始注意力质量。标签与随机差不能唯一归因为异常识别能力。所有随机运行各自计算指标，再平均成对差，不集成预测。

## 4. 数据、规模和退化边界

- 基准：原冻结 24 条序列，原始文件指纹、测试段、顺序不变。
- 合成：原保存的 27 条输入，统一采用已执行交叉对照的官方整序列标准化；输入、标签、随机掩码与对应父运行逐项核对。
- 官方单变量权重不变，Patch=16，配置窗口5000、batch=1；短序列仍使用自身长度。沿用 RCD_yyd、float32、TF32关闭和确定性设置。
- 每条序列运行 A 一次，标签及五个随机集合各运行 B/C/D × last/all，共37个条件，51条序列共1887条条件级预测。物理无操作条件可复用经验证的 A；重复的 last/all 情况仍保留条件记录。
- 五个随机种子沿用2024–2028，必须复用父运行实际抽样集合或逐项验证完全相同，而不仅是种子相同。
- S 为空时 B/C/D 均为 A，并计入总体；另报有干预的窗口覆盖。
- 若 S=V 或有效查询出现无可用key：同一窗口所有条件统一回退 A，并报告原因与点数，另报共同可干预点指标。不得让 D 空行输出零而 C 保留自身后正常执行，再将差值当作自身收益。
- 既有5000窗口运行未出现无干净参照情况，仍需启动时重新验证。任何新增回退或输入不匹配需先排查，不悄然改变样本集。
- 本轮固定5000，不根据结果再选择128点结果作主证据。128点、异常类型扩展和混合Patch拆分是后续独立协议。

## 5. 实现验收：先验证，再使用官方权重运行

当前注意力实现只接受 [B,T] 的key有效掩码，并自动扩展为 [B,1,1,T]；旧的reference_intervention只能整列屏蔽，不能直接实现B/C。新增二维连接掩码必须明确使用 [B,1,T,T] 的广播语义，不能直接把 [B,T,T] 传给旧接口。

采用实验专用、作用域明确的适配器，保留原投影、RoPE、缩放、输出和head运算。不得全局替换torch的attention函数。每次记录目标层及实际连接矩阵指纹，异常退出后恢复模型状态。

必须通过：

1. 小型确定性attention与手工softmax矩阵一致；行query/列key方向、对角线、padding及全部四个布尔真值表正确。
2. 无操作的二维mask路径与原官方forward一致；若触发不同内核导致数值差异，保留原容差和失败记录，先复核，不为通过而放宽容差。
3. D-all与上一轮的整列硬屏蔽在相同输入上对齐；A与既有公共API基线对齐。新旧条件使用相同attention路径，避免仅某个条件改变内核。
4. last时，干预前层及最后一层输入/Q/K/V与A相同；B相对A只能改变S查询；C相对D只能改变S查询。对应非S输出应在数值容差内一致。
5. all时，固定预处理并只扰动S的输入：C和D的非S输出不变；C与D的非S输出彼此一致。这是当前模型拓扑的强约束，失败应优先视作实现或假设问题。
6. S为空、S=V、单有效Patch、部分有效Patch、padding-only Patch、混合Patch和多层调用次数均有测试；禁止全False行进入有效点计算。
7. 每层实际收到的mask可审计；参数指纹前后相同，hook/adapter在正常与异常退出后均清理。

先运行微型模型及固定输入单例验证。官方权重数值验证的样本按冻结顺序和边界覆盖选，不按效果选择；不基于单例效果调节方法。任何关键检查失败时，不进入完整运行。

## 6. 指标与统计

- 主指标：整序列概率AP；补充logit AP、ROC-AUC、按正常/异常类别的配对分数变化及窗内/跨窗排序分解。
- 额外按“选中Patch内异常点、选中Patch内正常点、未选中Patch正常点”记录输出变化。类别均值不是阈值误报/漏报率；不优化阈值。
- 基准按序列等权计算配对差，bootstrap2000次、seed2024，报告点估计和95%区间；随机种子在每条序列内部平均，不把24×5当成120个独立样本。
- 基准同时报告9个来源的来源均值、逐来源方向和逐一剔除来源的敏感性，不将序列bootstrap区间解释为跨来源普适性保证。
- 合成按5/500/2000异常点分别报告，先平均同一生成种子的三个布局，再按三个生成种子bootstrap；三个种子不足以支持强泛化结论。原始逐种子、逐布局效果全部保留。
- 0.01为描述性AP变化阈值，不是显著性标准。主对比预先固定，其余层、来源、类别和交互对比均作为探索性分析，不从多个分组中选择有利区间作确认性结论。
- 同一开发数据已被反复分析，所有新机制结论均需未来独立数据或新增生成种子验证，不能把本轮后续诊断称为最终基准结果。

## 7. 结果解释与停止条件

- C优于D且B劣于A：自身连接删除与性能损失有关；是否恢复到A、随机是否同样恢复需要另外看，不能归因于“自身信息单独被恢复”。
- C优于A且超过对应随机：支持当前条件下该连接选择值得进一步诊断，仍未排除空间结构和注意力质量差异。
- 只有last恢复、all不恢复：说明效果随干预层范围变化；不直接宣称已证明分布外失配或多层污染。
- C、D均退化：当前连接干预没有解决问题，不否定所有可靠参照方法；优先检查混合Patch和内容结构，而不是临时更换主数据或窗口。
- 数值、掩码拓扑、输入或权重检查失败：停止机制解释，保留失败目录并先定位实现问题。

每轮独立目录保存协议版本及指纹、运行环境、权重与输入指纹、父运行链接、每层mask审计、完整分数、指标和所有失败记录。结果出来后不得追改主比较；需要新假设时另立协议。
