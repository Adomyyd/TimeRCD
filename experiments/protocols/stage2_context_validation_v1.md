## A：还原异常段，测影响半径

### 输入构造

- 生成18条长度5000的干净基准：seed 3101–3118，`sin(2πt/64) + N(0,0.1)`。
- 对每个seed构造中心孤立事件、中心成簇事件、左右边界孤立事件、左右边界成簇事件，共6条/seed、108条。事件幅度为+4；中心孤立为`[2496,2512)`，中心成簇为`[2464,2480)、[2496,2512)、[2528,2544)`；前边界孤立为`[0,16)`，前边界成簇为`[0,16)、[32,48)、[64,80)`；后边界孤立为`[4984,5000)`，后边界成簇为`[4920,4936)、[4952,4968)、[4984,5000)`。所有范围均为半开区间。
- 记录`base`、`values`、标签及所有半开异常区间。对每条序列令`restored=values.copy()`并逐区间以`base`还原。验收区间外`values==base`逐点成立，且还原结果整体等于`base`（因此边界差分一致）。

### 推理与读出

- 两条件使用`values`计算的同一mean/std；每序列各跑`values`和`restored`。主读出`Δ=logit_original-logit_restored`。
- patch距离按目标patch集合的最小绝对索引差定义。异常点单列为ring 0；正常点按patch距离分箱：同异常patch、1、2、3、4–5、6–10、11–20、21–39、≥40。窗口左右侧分开统计；簇事件外分别按首末异常patch区分左/右，事件簇间点另列，异常所在patch中的正常点单独标记，不混入异常点。无点的一侧记空，不用0补值。
- 同时保存两条件各环的logit水平和配对差、辅助概率，以及辅助的点级平均绝对变化；按中心/边界、孤立/成簇分层。每条派生序列先在点级环内求均值；共享同一干净基准的布局在种子内等权平均，再以18条独立基准序列为单位bootstrap（seed 2024，10000次，95% percentile区间），不把同基准的6个布局视为独立样本。
- 主判据中的`|Δ|`指先求signed环均值再取绝对值，不是点级`mean(|Δ|)`；后者只作辅助。局部判据的5%以异常点ring0的均值绝对值为分母。影响半径则按交接说明的“峰值5%”定义，以所有非空合并环均值绝对值的最大值为峰值，从ring1起报告首次低于峰值5%的环下界；逐序列和总体各报，不跨缺失环插值。峰值为0或未达到时不强行给数。

## B：截断远处上下文，测边际贡献

- 使用同一组18个seed生成长度5000的干净信号。固定32点目标`[2480,2512)`（patch 155–156），分别构造正常目标和+4异常目标；同一seed的两个目标条件共用从异常输入计算的mean/std。
- 所有条件始终保留目标及其前后各5个patch。变化半径`r∈{0,1,2,5,10,20,40,full}`表示在固定±5之外额外开放r层patch；有限r条件在对目标patch集合的最小patch距离`d`上保留`d≤5+r`的上下文，`full`保留全部有效patch。掩码按patch生成并扩展为16点有效掩码；5000点窗口末patch仅前8点有效，padding不得标为有效。
- 每个seed、目标类别和r只读取32点目标的平均logit；同时报告相对r=0的变化。逐seed配对后bootstrap（seed 2024，10000次，95% percentile区间）。分别绘制正常/异常目标的半径曲线。
- 饱和半径按最小r定义：从r至full的绝对差小于`|score(full)-score(0)|`的5%；总变化为0时标记不适用。`full`仅为端点，不纳入有限半径排序。
- 报告必须说明截断会改变softmax分母；曲线描述可见上下文范围，不是单patch因果效应。只比较固定目标分数，不跨条件比较AP。

## 解释判据与停止

- A若环≥3的绝对效应低于ring 0的5%且区间包含0，才按协议称影响局部；若效应延伸至≥20 patch，称影响跨较远上下文。同步报告数值，避免把单一判据写成普遍定律。
- B若r=10达到预定饱和定义，描述为该设置下较远上下文边际较小；若r=40仍明显偏离full，描述为范围曲线仍未饱和。区间跨零不作为等效证明。
- GPU仍繁忙时不启动官方推理；本轮可完成数据/逻辑实现与CPU测试，但不得将其写成实验结果。
- 实现层GPU门禁固定要求所选GPU利用率≤25%、空闲显存≥6000 MiB。运行时先用`CUDA_VISIBLE_DEVICES=<空闲卡>`选择空闲GPU，再运行`conda run -n RCD_yyd python -m experiments.stage2_context_validation.run --config experiments/configs/stage2_context_validation_v1.json`；统计入口：`conda run -n RCD_yyd python -m experiments.stage2_context_validation.analyze <run_directory>`。
