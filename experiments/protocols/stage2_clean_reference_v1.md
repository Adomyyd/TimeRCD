# E07：最后一层干净反事实参照替换（执行前协议，2026-11-05）

## 问题与解释范围

E06已知全层P_C在开发基准AP退化，P异常—N正常是最大平均AUC损失项，但权重约77%、区间跨零。本轮问：在产生P的受控合成数据上，删除参照与替换参照内容是否产生不同结果？最后一层的V内容与K相关注意力重分配是否可区分？所有比较为冻结官方模型的探索性诊断，干净分支不可部署、不保证是性能上界。

## 冻结数据

- 8个新生成种子3101–3108；每种子一条长度5000的干净信号：周期64正弦+标准差0.1独立高斯噪声。
- 每条异常输入恰含640异常点（12.8%）；事件长度5/32/128，对应128/20/5个互不重叠事件。位置先取等距槽中心、向下对齐16，再平移0或8点。所有事件均完整且不触及末端；长度5无P，为无操作对照。
- 形态三种：正偏移+4、负偏移−4、事件内交替±4（首点+4）。固定绝对扰动幅度与能量；第三种仅代表高频交替扰动，不等于所有方差异常。事件数、布局、形态与M/P覆盖共同变化，不将事件长度对比解释为单一持续时间因果效应。
- 共8×3形态×3长度×2对齐=144条新输入。主统计限于96条长事件，48条短事件验证P为空。每个种子的干净噪声跨形态、长度和对齐复用，相关性按种子聚合处理。
- 每对共享**异常输入的整序列均值/标准差**：异常分支完全遵循官方标准化；干净分支也用这组统计量，避免两分支标准化尺度不同。干净分支不是独立调用官方归一化得到的干净输入。保存原始及标准化两分支、标签、事件位置、统计量、类型、哈希。
- 另复用E05的27条旧合成输入，仅做A父输出回归与P空集合回归，不混入新统计，不需重建干净反事实。

## 条件及连接定义

目标为当前输入的全异常有效Patch P；保留对角自身连接。固定异常分支前层输出；干净分支独立无干预跑至最后一层，截取投影后、RoPE后的K及投影后的V，位置与有效掩码对齐。

1. A：原模型；最后一层使用显式softmax基准，与官方SDPA路径检查数值一致。
2. C：仅最后一层，禁止其他查询读取P，保留P自身。
3. V：仅最后一层，固定异常分支Q/K及全部注意力权重。仅对j∈P且i≠j，将边(i,j)的V替换为干净V_j；自身边仍使用原V_i。
4. KV：同一边集合替换K_j和V_j，保留异常Q_i；计算q_i·k_clean_j后重算每行softmax。对角logit和对角V保持原分支值，但对角注意力概率可能因分母变化而改变。
5. C_all：所有层执行同一P_C，作为层范围桥接辅助条件。C_all与V/KV不是匹配层范围的内容因果比较。

V是query-dependent边值，不能简单整列替换后忘记恢复自身；实现以原V矩阵加受干预边权重乘(cleanV−V)，对角差项严格为0。KV同理，logit只替换非对角目标列。正常Patch的干净表示也可能受其干净上下文影响，但本轮只搬运目标P的K/V。

## 预定比较和读出

- **主要比较**：长事件集合V−A、KV−V的P异常—N正常条件AUC；辅以同点对的加权AUC贡献和P异常平均分数。若主条件AUC为空则标记缺失，禁止填0。
- 必须伴随报告C−A、V−C、KV−C、KV−A以及C_all−A，完整序列AP/AUC和M异常—N正常；分数均值不是漏报率，AUC分解不是AP归因。
- 主分数为概率，logits补充。每个生成种子内先等权平均长事件的形态/长度/对齐，再按8个种子bootstrap（seed2024，10000次）。分形态、长度、对齐及其完整交叉分层同样按种子配对。输出全部逐例和逐种子结果；不将144条视作独立样本。
- 固定对齐差分：先在种子内计算offset8与offset0的干预效应之差，按形态/长度报告。所有区间描述性，未做多重检验校正；不按区间挑选形态。
- 若C未复现损失而C_all复现，只能将结果解释为层范围不同；若两者均未复现基准损失，则优先修订合成覆盖，不直接推至全层替换或训练模块。

## 验收、失败与溯源

- RCD_yyd，官方冻结checkpoint、batch1、确定性float32、TF32关闭，运行前确认GPU空闲。沿用父检查容差atol=rtol=1e−5，不按结果放宽。
- 无模型测试：逐边手算V/KV验证自身、方向、padding；空目标、原内容回填、单目标自身输出；共享归一化；固定异常量/能量/不重叠；分解/种子统计；异常退出恢复hook。
- 所有新输入和覆盖清单先保存、检查。gate由首种子×三形态×长度5/32×对齐0/8预定选取，共12例，包含P空、P有、M空、M有。先跑gate再完整运行，gate结果不纳入效应统计。
- 每例A对齐官方标准化输入和官方forward；C对齐既有last层edge适配器；V/KV及C的最后一层输入和原Q/K/V与A一致；V权重与A逐点一致；KV对角logit及替换边集合核验。每例原内容回填V/KV与A一致，空P条件为无操作。gate另做显式空选择、干净K/V张量保存、有限值及模型状态检查。
- 旧27条A和P_C对齐E05保存分数/logits，并记录父输入SHA256。检查模型参数/缓冲区前后SHA256相同。失败保留新目录、数组、异常和失败状态，停止正式运行，不覆盖旧产物。
- 独立运行保存协议、完整源代码、配置、环境、权重和父文件哈希、输入/分数/选集合、逐项检查、指标/排序贡献/分数变化、统计及报告；结束更新根目录实验记录。
