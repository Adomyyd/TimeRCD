## 1. 最终目标与当前范围

最终研究目标：增强 TimeRCD 的 H，使其支持正常预期、异常判别及上下文关联、偏离形态与程度的读取；进一步验证可组合异常基元在少样本故障类型识别中的价值。H 可能已包含这些信息，研究的是监督与显式提取是否有效，而不是预设原 H 没有信息。

当前只推进正常参考监督的最小验证，不一次性实现最终架构。P0/P1/P2 的配置、共享代码和统一入口已完成，下一步是先做 audit/smoke，再按登记协议训练；阶段递进指实验因素递进，不指沿用上一组训练权重逐层叠加。每组内部仍联合训练。

符号：X 为完整观测，X^0 为生成器提供的配对正常序列，Y 为时间异常标签，V 为有效时间标志，M 为随机抽中位置标志。X、X^0 必须处于同一数值坐标，X^0/Y 不作为模型输入。M 与 padding 标志 V 严格分开。

## 2. 原方法与掩码的已核实事实

【核实：2026-11-09 重读】项目内 2026 论文第 3–4 页 §2.2、附录 C.3/C.4（第 22 页）；training.py:188–224、:133–185、:394–423；time_rcd/_core/ts_encoder_bi_bias.py:120–159、:327–374。论文公开入口：https://arxiv.org/html/2509.21190 。

- 原方法按有效 patch 均匀随机选择 floor(0.15P) 个，patch 内数值置零，多通道一起处理；不按异常标签挑选。
- 被遮 patch 不删除：训练传入的时间点可见标志为 V & ~M，编码器按每个模型 patch 聚合为 `sum > 0`；整个 token 无可见点时才屏蔽其 key/value，查询仍保留。默认编码器和采样块同为 16 时，抽中的完整 patch 会被屏蔽；若单独将采样块改为 4，部分被遮的 16 点 token 仍可被其他查询读取。
- Transformer 先将 patch 线性投影，再双向注意力建模；原时间投影将每个 patch 特征展开成不同时间位置的特征 H，不是复制同一个向量。
- 原重构头输出全部位置数值，MSE 仅在 M 选中的有效位置计算；目标是实际观测 X，正常和异常位置都可能入选，不是只恢复正常段。
- 异常分类与重构使用同一次遮蔽前向；分类并不排除 M 位置。论文正文用 sigmoid/BCE 概括，附录 C.4 与代码采用双 logits/CE。
- 推理完整输入，只使用异常头。掩码重构是训练辅助，不是测试时以重构误差打分。

【2026-11-10 全链路补核】官方历史训练入口 `ebf4f056b571f7ea90602ef666ae56f7d717ebfe/training.py` 与当前 400k 入口均采用 `config = default_config` 后原地设置 patch=16；单 GPU 直接调用、workers=0 时遮挡函数也读取 16，比例 0.15。配置类初始默认值 4 不能当成运行值。P0/P1/P2 已显式统一为 `model.patch_size=16`、`input.mask_patch_size=16`、`input.mask_ratio=0.15`。P1/P2 的 M 只用于损失采样，不遮蔽输入。当前官方 main 库默认 4/噪声替换、多 GPU spawn 全局重新初始化是不同路径，不作为当前基线；源码、哈希与验证见 `experiments/ablation_v9/audits/patch_20261110/REPORT.md`。

【推断】掩码补全促使模型预测缺失观测，却不直接规定正常参考或偏离语义。配对正常监督规定预测目标，但完整输入可能允许复制、平滑或合成伪迹捷径；不能认定它已经替代掩码的上下文约束。随机独立异常被遮住后可能无法准确恢复，因此不能无条件把原掩码施加到未来所有偏离目标。

## 3. 当前目标方案 P2：完整输入、15% 位置正常参考预测

### 3.1 结构与公式

沿用原 Transformer F、时间投影、重构头 R、异常头 C_H，不增加 N/E 或 B/Z：

\[
H=F_\theta(X,V),\qquad \hat X^0=R_\phi(H),\qquad
\ell=\operatorname{Mean}_{c}C_H(H),\qquad
S=\operatorname{softmax}(\ell)_{1}.
\]

设通道数为 C，损失按 batch 内有效选中元素平均：

\[
L_{n,M}=\frac{\sum_{b,t,c}M_{bt}V_{bt}(\hat X^0_{btc}-X^0_{btc})^2}
{C\sum_{b,t}M_{bt}V_{bt}},\qquad
L_c=\operatorname{CE}_V(\ell,Y),\qquad L=L_{n,M}+L_c.
\]

首版两项权重均取 1，与原流程加权方式一致；若调整，所有相关对照同协议登记。分母为零时须显式跳过该重构项并记录，不能产生 NaN；不为短序列偷偷改变 15% 抽样规则。

M 仅用于选择损失位置：不清零 X、不将 M 传给 F、不按异常标签选择 M、不把预测值强行置零。选中的正常与异常位置均预测 X^0。正常位置配对相等时目标等于观测，存在复制捷径；Y=0 与 X=X^0 不必严格等价，须保留配对语义审计。

### 3.2 与原版完全一致的头结构

d=d_proj，p=config.dropout。当前原版 400k 入口采用 d=256、p=0.1、patch_size=16；实施时核对实际配置快照。

| 模块 | 结构 |
|---|---|
| R | Linear(d,4d) → GELU → Dropout(p) → Linear(4d,4d) → GELU → Dropout(p) → Linear(4d,1) |
| C_H | Linear(d,floor(d/2)) → GELU → Dropout(p) → Linear(floor(d/2),2) |

来源：training.py:101、:112；重复定义 time_rcd/_core/TimeRCD_pretrain_multi.py:56、:67。R 逐时间逐通道共享参数，预测统一归一化坐标下的数值；C_H 输出通道 logits，再按原规则平均。CE 作用 logits，不对 softmax 概率再次做 CE。

P2 只将原重构目标改为 X^0，并取消输入遮蔽；原异常头仍直接读取 H。旧版“分类必须读取 Z”只适用于后续 P4，不能套用到此阶段。

### 3.3 一次训练迭代

1. 读取 (X,X^0,Y,V)，在标签二值化前保存有效标志。
2. 对配对序列应用同一变换，统计量不能依赖仅训练可见的 X^0；训练／推理差异单独登记。
3. 按有效 patch 随机抽取约 15%，生成 M，与正常／异常标签无关。
4. 完整 X 和 V 进入 F，一次前向得到 H，再计算正常参考和分类 logits。
5. 在 M∩V 上计算正常参考 MSE，在所有有效时间位置计算分类 CE。
6. 求和后一次反向传播，联合更新已登记范围内的骨干、R、C_H。X^0/Y 仅为监督。

梯度：L_n 更新 F、R；L_c 更新 F、C_H。部署为完整 X→F→C_H；正常参考可作为额外诊断输出，不默认改用其误差打分。

## 4. 分步消融与归因

| 阶段 | 输入 | 数值监督与分类 | 要回答的问题 |
|---|---|---|---|
| P0 | 原版遮蔽 15% patch | 选中位置预测 X；原异常分类 | 原流程基线 |
| P1 | 完整 X | 同规则选中 15% 位置预测 X；同分类 | P1−P0：输入可见性（置零及注意力屏蔽一起取消）的影响 |
| P2（当前目标） | 完整 X | 同规则选中 15% 位置预测 X^0；同分类 | P2−P1：正常参考监督的增量 |
| P3（后续） | 完整 X | H 直接接正常、偏离、异常三个头 | 偏离监督的增量 |
| P4（后续） | 完整 X | H→B/Z；正常、偏离、分类三任务 | 显式提取结构的增量 |
| P5（后续） | 依据已验证方案 | Z≈UA，故障类型少样本适配 | 基元是否超过直接特征适配 |

P0/P1/P2 的重构监督位置规则完全相同，不将 P1 改成全位置重构。15% 以 patch 为单位，不另改成随机时间点。验证使用固定、可复现的 M；训练的抽样随机源宜独立记录，以避免结构变化影响抽样序列。P1−P0 同时改变值置零和注意力屏蔽，不解释成其中任一项的单独作用。

P3/P4 比较时先沿用相同 15% 数值监督位置策略；若扩大到全位置，单独增加监督覆盖率对照，不能同时改变结构和覆盖率后归因。当前不提前决定偏离损失最优权重或额外掩码分支。

P4 必须保留同监督直接 H、容量匹配普通 MLP／共享适配器、去掉偏离损失、去掉正常参考损失等关键对照；单个头相同不等于总参数量相同。删除损失后未被训练的输出不作公平重构比较。自由条件解码、简单数值残差属于后续对照。

### 4.1 初始化、预算与实现一致性

- 已有 400k 原流程为从头训练，不是官方检查点继续训练，也不是我们的新方案训练。保留其产物，不重复启动或中断。
- 若后续也从头训练，匹配数据、初始参数分布、划分、训练步数及选择规则；相同种子不自动保证不同结构的共享参数一致，须显式核对。
- 若用已有训练完成后的固定检查点做小预算消融，所有组从同一不可变检查点独立启动，并包含原方法同预算继续训练 P0。登记 checkpoint 哈希、优化器是否重置、输出头是否继承；禁止一组继续训练、一组从头训练后直接归因。
- P0/P1/P2 结构相同，应尽可能复制相同初始模型状态；P3/P4 新增头使用一致初始化规则，并控制已有头的继承策略。此前 v8.1“加载骨干、新头随机”的设想不再是唯一既定协议。
- 原代码 padding 处理错误与预处理差异不能混入方法收益。既有原样运行保持不动；新消融组统一有效位置处理，必要时登记修正版 P0。原版历史结果不单独承担严格因果对照。
- 各组固定相同数据／分组、优化器、学习率、batch、训练步数、验证频率及检查点选择规则，报告参数量与实际计算开销。不同目标的总损失不可直接跨组比较；早停需披露实际预算，不能仅说最多同样轮数。
- 具体初始化路线、子集规模、预算、种子集合、停止阈值及验证指标须在实现／开跑前登记；本次不擅自确定或启动。

## 5. 评价与进入下一阶段的条件

先做小规模接口与梯度检查，再做同预算筛选，最后对关键组多种子确认。不得把未确认的筛选结果写成最终结论。

P2 必须报告：
1. 正常参考误差：在标签正常／异常区域分别报告，并按配对差值是否非零补充解释；同时报告复制基线 X 作为正常预测的误差。低总误差不能掩盖异常处复制失败。
2. 抽样覆盖：每批／每轮被选正常、异常位置数量；验证固定 M，并额外报告全有效区域误差。后者是评价，不改变训练覆盖率。
3. 异常检测：统一外部评价协议（如 VUS-PR）与正常误报指标；阈值若需要，仅由训练／验证信息确定，不在测试集挑阈值。
4. 密度分层：在已有数据按局部占比、事件长度与频率报告；总体平均改善不等于密集场景改善。
5. 正常参照／上下文证据：典型波形及合法上下文干预；干预目标必须有定义，任意破坏输入只能说明敏感性，不能证明正确理解上下文。

推进条件：接口、有效标志与目标坐标正确；在异常／实际变化区域，正常参考相对复制基线有可重复恢复能力；P2 对 P1 的检测变化有稳定证据并明确适用条件，才将“正常参考监督有效”作为后续前提。数值门槛预先登记，不事后选择。只改善正常参考但不改善检测时，保留两项结果并诊断任务冲突；若后续仍探索偏离任务，必须登记为新假设，不能声称前一步检测假设已成立。

若 P2≈P1，优先检查覆盖、配对、复制与局部捷径，不用增加模块掩盖失败；若 P4≈P3，不主张分支必要性；若基元不超过直接 H/Z 的同分类器适配，不主张通用基元价值。重构低误差不证明解耦或正确注意力。

## 6. 后续 B/Z 候选与长期研究目标

以下保留最终方向，不是当前实现任务：

\[
H=F(X,V),\quad B=N(H),\quad Z=E(H),\quad
\hat X^0=D_n(B),\quad \widehat{\Delta X}=D_a(Z),\quad
\hat X=\hat X^0+\widehat{\Delta X}.
\]

分类头 C_Z 只读取 Z。N/E 为参数独立的 d→d→d 两层 MLP（中间 GELU），B/Z 与 H 同维。D_n/D_a 完整复用第 3.2 节 R 的结构、参数独立；C_Z 复用 C_H 结构。结构复用不等于权重共享或默认继承权重。

正常和异常位置都提取并使用预测 Z，不按真实标签置零。D_a 只读取 Z，不从 B/H 旁路读取变化；正常参考直接由 D_n(B) 给出，普通带偏置 MLP 不保证 D_a(0)=0。三个监督目标为 X^0、X−X^0、Y，逐步引入；具体数值监督位置按阶段匹配，不恢复旧版默认全位置三损失的即时执行方案。

数值相加是配对差值参数化，不等同于物理故障线性叠加。B/Z 不保证纯净、独立；二分类标签不直接监督事件归属或异常类型。未来 Z≈UA 中 U 是异常基元字典，A 是时序组合系数；基元可能是一组方向／子空间，正交不等于独立或可解释。任意异常由有限基元表示是愿景，不是前提。

后续对照包括简单残差、普通瓶颈／条件自编码器、同监督 H、PCA／简单字典，以及“表征约束有／无 × 基元有／无”。真实少样本同分类器、同标签、同事件边界比较 H/Z/A。自动扩容与不确定性暂缓。

## 7. 数据与证据边界

沿用现有生成配置，不调整异常数量、密度、类型或采样规则。当前生成器支持连续、多点和局部密集异常，但不等于官方检查点训练履历或覆盖充分。单变量 35% 标签上限不能直接套用最终多变量标签。

配对 X^0 是生成器对应目标，不自动等于独立因果反事实。生成器共享缩放依赖异常观测，部分噪声过程读取异常形态；部分干预可能改变后续波形而标签只覆盖边界。先核查并报告，不擅自改标签或生成配置。

原训练用 batch 观测统计处理配对，推理标准化可能不同；所有组保持或统一修正同一协议并披露，不能只修正新方法。原训练随机 95/5 划分尚未验证背景分组；同基底干预副本、同运行相邻窗口不跨 split 的要求若需调整，应对全部新组一致处理，不能与旧随机划分直接作严格归因。

TSB-AD 时间异常标签不是故障类型真值。真实类型数据集待定，无配对真实数据不伪造 X^0。官方预训练暴露未完全追溯，区分适配未见与整个预训练未见。

原代码事实继续保留：training.py:71 读取配对，:172 有 padding 过滤问题，:240 为 batch 标准化，优化器包含骨干；ts_multi_generator.py:610 共同缩放，ts_generator.py:1773 起噪声读取异常形态。骨干更新后旧冻结缓存失效。最近邻全文调研仍需补核，不能因用了分支或残差就宣称首次。
