# 研究问题和思路

版本：v9。更新时间：2026-11-09。状态：P0/P1/P2 工程代码已实现，尚未训练或测评；最终 B/Z 架构尚未实现，未获得实验增益。数据生成配置沿用现状。

## 1. 核心研究问题

本研究希望增强 TimeRCD 的上下文表征约束，使 Transformer 特征 H 能支持提取三类信息：

1. 正常预期：结合工况、周期、趋势及其他上下文，当前位置在正常状态下应是什么样。
2. 异常语义：当前位置是否异常，以及它与相关跨 patch 异常事件的关系。
3. 异常偏离：实际观测相对于正常预期发生了什么变化，以及变化程度。

这三项是功能目标，不预设 H 天然存在三个互斥子空间。H 可能已经包含这些信息；研究增量不是声称创造了原先不存在的信息，而是用明确监督引导其提取与利用。

> 在保持数据生成配置不变的条件下，正常参考预测、异常偏离重构与异常判别的联合监督，能否引导模型更有效地利用正常背景和相关异常上下文，缓解异常结构被吸收为正常参照的问题，并得到比直接使用 H 更有迁移价值的异常表征？

研究链条：**正常预期与偏离监督 → 上下文异常表征 → 可组合异常基元 → 少样本故障类型识别**。第一阶段先验证表征职责和上下文使用；基元、未见组合与少样本仍是后续研究目标，自动扩容和不确定性暂缓。

## 2. TimeRCD 的定位与失效假设

【核实：既有代码审计】TimeRCD 已经使用 Transformer 建模上下文，并以合成上下文相关异常标签监督异常分类，重构观测作为辅助任务。其输出是逐时间异常分数，不是整段单一全局分数；不能称其完全没有上下文比较或监督。当前项目 training.py 的重构目标是观测 X，不是配对正常参考 X^0。

【核实：2026-11-09 论文核查】TimeRCD 当前论文 Limitations 明确指出，同一大窗口中频繁出现的异常点可能被部分吸收进局部参考模式，削弱异常信号，并以 Stock 为例。原文：
> frequent outliers inside the same window may be partially absorbed into the local reference pattern, weakening the anomaly signal.

来源：https://arxiv.org/html/2509.21190 。该版本表 8 中 Stock 的平均异常率为 9.4%。平均异常率不能代表局部窗口的密度；异常频率、持续时间、间隔和重复形态应分开理解。该限制在本次核对的当前版本及项目内 2026 论文中存在，不把它回填为所有早期版本都有的表述。

【推断／待验证】正常参照受到异常结构影响，可能是高异常负荷场景中偏离被低估的机制之一。新增正常参考与偏离监督可能缓解这一问题，但论文描述不是对注意力因果机制的证明。

不写成“模型一定关注了无关异常”“注意力被稀释已经证实”“H 缺少异常信息”。异常上下文本身可能提供事件起始、持续、演变与恢复证据；不能将其全部视为污染。关注哪些上下文，应由任务表现与受控干预检验，不能仅看注意力图。

## 3. 最终目标架构及监督职责（后续候选，不是下一步全量实现）

完整观测仅作一次骨干前向：

\[
H=F(X),\quad B=N(H),\quad Z=E(H).
\]

B 表示正常状态特征，Z 表示异常偏离特征；二者保留必要时间结构。“整个 H”不等于全局池化成一个向量。

后续 B/Z 分支候选将条件重构具体化为：

\[
\hat X^0=D_n(B),\qquad
\widehat{\Delta X}=D_a(Z),\qquad
\hat X=\hat X^0+\widehat{\Delta X},\qquad
\ell=\operatorname{Mean}_{\mathrm{channel}}C(Z),\qquad S=\operatorname{softmax}(\ell)_{\mathrm{anomaly}}.
\]

2026-11-09 固定后续分支方案的模块结构：B、Z 与 H 的末维均为 d=d_proj；N、E 为参数独立的逐位置两层 MLP（d→d→d，中间 GELU），不压缩维度。D_n、D_a 各自完整复用 TimeRCD 原重构头结构（d→4d→4d→1，两个隐藏层各带 GELU 和原配置 Dropout），参数独立；C 复用原异常头结构（d→floor(d/2)→2，隐藏层 GELU 和原配置 Dropout）。异常 logits 按原规则先做通道均值，再 softmax，并使用交叉熵监督。结构复用不等于共享参数或默认继承原头权重。详见方法设计.md 第 2 节。

训练监督分别为正常参考 X^0、配对差值 X-X^0、时间异常标签 Y。X^0 和 Y 不作为部署输入，也不用真实标签开关分支。正常与异常位置均提取并使用预测的 Z。

| 目标 | 直接要求 | 不能自动推出 |
|---|---|---|
| 正常参考预测 | B 足以恢复生成器提供的正常对应状态 | B 完全不含异常，或模型必然正确使用完整背景 |
| 偏离重构 | 从 Z 能恢复观测与正常参考的具体差异 | Z 不含任何背景、每一维具有机制语义 |
| 从 Z 异常分类 | Z 能支持正常／异常判断 | 二分类标签直接监督异常类型或事件归属 |

偏离解码器只读取 Z，限制“Z 仅作开关、从 B 读取全部异常”的捷径；仍需验证其他捷径。正常位置若 X=X^0，其偏离输出目标为零，但不强制潜在 Z 为零。默认不加入正常 Z 范数正则。

输出相加是对齐数值的差值参数化，不假定故障的物理生成机制是线性加性。自由条件解码 D(B,Z) 保留为结构对照；遮蔽、配对特征一致性和额外时序聚合均非当前必需模块。

【推断】这些任务增加了使用正常参照和异常变化信息的训练压力，但不能保证模型必须关注正确上下文。正常参考在长异常、工况歧义或信息不足时可能无法唯一恢复；正常参考输出不是已经获得的真实因果反事实。

## 3.1 当前第一步：正常参考监督是否有用

2026-11-09 用户确认逐步验证，先完成最小变化，不能把完整 B/Z 方法一次性实现后再猜测效果来源。最终目标仍是增强正常参考与异常偏离的上下文表征，再验证可组合基元和少样本迁移；它不是第一步实验已经具备的能力。

当前目标方案 P2：完整观测 X 输入原 Transformer，H 直接连接原结构重构头 R 和异常头 C_H；随机选取约 15% 的有效 patch，只在这些位置预测配对正常值 X^0，同时在所有有效时间位置做异常分类。暂不增加 N/E、B/Z、偏离头、基元或不确定性。

\[
H=F(X,V),\quad \hat X^0=R(H),\quad
\ell=\operatorname{Mean}_{c}C_H(H),\quad
L=L_{n,M}+L_c.
\]

M 是重构损失位置选择标志，不是输入遮蔽标志。完整 X 不置零，Transformer 只接收 padding 有效标志 V。均匀抽样约 15% patch 不区分正常／异常；配对正常真值 X^0 和标签 Y 只作为监督。

【推断】正常参考监督能够惩罚异常位置的直接复制，但正常区域仍可能靠复制完成，模型也可能依赖局部平滑或合成伪迹。15% 抽样没有原掩码补全的信息缺失约束，不保证充分使用上下文、学会反事实或完成解耦。

必要的第一阶段对照：P0 为原流程（输入遮蔽 15%、在选中位置预测 X）；P1 为完整输入、同样抽取 15% 位置预测 X；P2 为完整输入、同样位置预测 X^0。三组保留原异常分类任务。P1 与 P0 比较输入可见性变化，P2 与 P1 比较正常参考目标变化。P1 不改成全位置重构，否则同时改变监督覆盖率。

后续顺序为：P3 在 H 上增加偏离重构 → P4 引入 B/Z 分支并做容量／删除损失对照 → P5 验证异常基元与少样本迁移。各组独立初始化并匹配预算，不默认把前一组训练后的权重顺序传给后一组。每组内部联合训练，具体推进条件见方法设计.md。

当前 P0/P1/P2 代码已写入 experiments/ablation_v9/，但尚未启动训练；现有 experiments/train_400k.py 原流程从头训练仍在运行，不能误记为没有任何活动实验或官方权重继续训练。本次不启动新任务、不干预既有训练。

## 4. 数据范围与当前决定

用户于 2026-11-09 明确决定：沿用当前数据生成配置，本轮只修改研究表述，不调整异常密度、类型、数量、采样概率或生成规则，不生成新数据。

【核实：当前项目代码】单变量生成路径会拒绝标签占比超过 35% 的序列，支持连续异常及多个异常点；异常样本比例 1.0 指样本要求含异常，不指每条序列所有位置异常。局部密集、整序列高占比及异常事件多是不同概念。多变量最终标签不能简单套用单变量 35% 上限。

【核实：来源边界】当前项目远端为 Adomyyd/TimeRCD；本次检查的官方 thu-sail-lab/Time-RCD 文件树未包含当前 dataset_gen 文件。当前生成器行为不等于官方检查点的完整训练履历；本次没有统计实际训练语料的密度分布。

“配置保持不变”是研究控制变量选择，不升级为“数据覆盖已经证明充分”。也不以“TimeRCD 未见过密集异常”作为立论前提。后续可以在已有数据中只读分析密度和配对质量，但这不是要求修改生成配置或本次启动实验。

## 5. 基元、少样本与创新边界

在 Z 的职责得到验证后，再研究 Z≈UA：U 为共享异常方向或子空间，A 为带符号的时序组合系数。U 与正常特征 B 分开命名。机制可以对应一组方向，基元不是完整故障类别；正交不等于独立或可解释，潜在组合不保证物理波形线性叠加。

目标是预训练学习尽可能丰富、可复用的异常成分，下游用少量故障类型标注学习组合与类别的关系。不能承诺任意异常由有限字典表达；未知组合、未知机制、拒识和新类适配分别验证。自动扩容与分量不确定性后置。

最强质疑：“这不就是正常参考／残差辅助的多任务学习，给 H 加几个头吗？”这是必须正面比较的近邻解释。H 直接接相同监督的强基线应获得相同数据、正常参考、标签和训练预算。复用输出头结构只是控制单个头的架构变量，总参数量仍因新增提取器和分支增加，需加入容量对照；不把新 MLP 当作贡献。如果结构化 Z 或基元不能额外改善上下文利用、跨背景与少样本表现，应缩小贡献主张。

## 6. 可证伪假设与统一表述

| 假设 | 最小验证 | 反例或否定结果 |
|---|---|---|
| 正常与偏离职责可读出 | 分别评价正常参考、偏离及相加重构；分正常／异常报告 | 正常分支复制异常；偏离分支只能分类而不能恢复变化 |
| 模型更合理地利用上下文 | 合法的同目标、不同背景／事件上下文对照 | 忽略上下文、依赖局部合成伪迹，或仅对任意破坏敏感 |
| 密集异常下正常参照更稳定 | 已有数据内按局部占比、事件长度和频率分层，同数据同预算比较 | 只改善均值、不改善对应场景，或参考误差与检测变化不支持解释 |
| Z／基元有额外迁移价值 | H、Z、A 同分类器、同标签、同分组与预算比较 | 直接 H 同样好或更好，不能主张分解必要性 |

可直接使用的表述：

> TimeRCD 已通过上下文相关合成监督学习异常判别，但对正常预期、异常偏离及其上下文关系的表征职责缺少直接约束。针对频繁异常可能被吸收为局部正常参照的问题，本研究在保持数据生成配置不变的条件下，拟从完整上下文特征中提取正常状态与异常偏离表征，通过正常参考预测、偏离重构和异常判别提供明确监督，并检验模型是否更有效地利用正常背景及相关异常事件信息。在此基础上，进一步探索异常基元的组合表达与少样本迁移价值。

以上是研究计划，不是已证明结论。密集异常的注意力失效原因、事件语义和迁移增益均需实验验证。

以下保留前次 2026-11-08 专项检索的可追溯结果，本次是文档整理，没有重新检索或扩大核查范围。来源为 OpenAlex、Crossref、arXiv 正文及本地 TimeRCD 论文／代码；各条的证据范围如下。

| 工作 | 已核实内容与核查范围 | 对当前方案的约束 |
|---|---|---|
| [TimeRCD](https://arxiv.org/abs/2509.21190)，2025 预印本／本地 2026 论文版本 | 【核实】第 2 节、附录 C 与代码：自注意力隐式上下文比较，合成上下文相关标签、重构辅助和二分类头。官方仓库 https://github.com/thu-sail-lab/Time-RCD | 不能称其没有上下文建模或上下文监督；可以研究是否缺少可识别、可组合的偏差成分约束。 |
| [Anomaly Transformer](https://arxiv.org/abs/2110.02642)，ICLR 2022 | 【核实】正文：先验关联与序列关联的差异、minimax 学习。 | “显式上下文/关联差异”本身不是新贡献。 |
| [DCdetector](https://arxiv.org/abs/2306.10347)，2023 | 【核实】正文：patch-wise 与 in-patch 双注意力的对比学习。 | 需要区别一般对比表征学习与可组合机制基元。 |
| [TimeRadar](https://arxiv.org/abs/2602.19068)，2026 | 【核实】正文 §3.4、§3.5：在分数阶时频表示上聚合 patch 与上下文的余弦差异并训练 CDL；few-shot 部分冻结骨干适配重构头。 | 是显式偏差最直接的近邻；应加入同骨干的余弦偏差／CDL 风格对照，不能把偏差约束单独主张为创新。该文 few-shot 检测也不等同于故障类型 K-shot 分类。 |
| [Anlu](https://arxiv.org/abs/2610.06180)，2026 预印本 | 【核实】PDF §3：同一 query 配两个正常规则不同的 reference，标签冲突迫使模型使用 reference；冻结 TSFM 加参考记忆和门控 adapter。HTML 正文不完整，改核 PDF。 | 不能把“换上下文而改变标签”作为独创点。正文骨干为 Toto-style TSFM，不能称为直接改装本仓库 TimeRCD。 |
| [HieraNTP](https://arxiv.org/abs/2611.00945)，2026 预印本 | 【核实】正文 §3.3、§3.4：多尺度 token、局部统计和观测偏差构成结构化风险表示；冻结预测模块，用 XGBoost 学下游组合。 | “保留多维偏差供下游适配”已被直接研究。需要验证学习到的基元具有跨背景稳定性与留出组合价值，而非仅堆叠多个误差。 |
| [Normality Constraint Learning](https://arxiv.org/abs/2610.06453)，2026 预印本 | 【核实】正文 §4：少量正常 patch 特征经 SVD 构建正常子空间，再做 patch 适配与对比约束。 | 区分“正常模式子空间”和“异常干预方向字典”；应有正常子空间残差基线。 |
| [MemAE](https://arxiv.org/abs/1904.02639)，2019 | 【核实：摘要范围】正常原型记忆与稀疏检索重构。 | 记忆原型、稀疏编码不等于异常机制分解，不能仅凭模块名称区分贡献。 |
| [Adaptive Feature-Oriented Dictionary Learning and Sparse Classification Framework for Bearing Compound Fault Diagnosis](https://doi.org/10.1109/TIM.2024.3383498)，2024 | 【核实：Crossref 元数据＋OpenAlex 摘要范围】复合轴承故障的字典学习与稀疏分类；全文未核查。 | 字典用于复合故障诊断已有先例；应追踪其监督与划分协议。 |
| [Generalized Zero-Shot Learning Based on Diffusion Model and Multilabel Network for Compound Fault Diagnosis](https://doi.org/10.1109/TII.2025.3567388)，2025 | 【核实：Crossref 元数据＋OpenAlex 摘要范围】借助故障属性、生成模型与多标签分类识别复合故障；全文未核查。 | 单故障组合迁移到复合故障也已有研究；需区别已知属性定义的新组合与完全未知机制。 |
| [Mechanical Compound Fault Analysis Method Based on Shift Invariant Dictionary Learning and Improved FastICA Algorithm](https://doi.org/10.3390/machines9080144)，2021 | 【核实：Crossref 元数据与摘要范围】移位不变 K-SVD 与 FastICA 分离复合故障源。 | 真实故障的分量分解不是空白；时间平移和相位变化可能需要小子空间或卷积字典。 |


【推断／待验证】当前增量候选是正常参考与偏离监督是否改善上下文使用，以及结构化异常表示是否改善组合与少样本迁移；不把模块名称当贡献。残差辅助多任务、正常／异常因素分离与条件重构的最近邻全文仍需补核，既有调研不能证明首次。
